Расписание: три варианта

Прототипы на живых данных из CMS. У каждого свой главный способ найти нужный поток.

A · Под мой график

Первым блоком — ивент, выбранный вручную. Ниже навигатор по дням недели: отметил свободные дни — остались курсы, где все занятия в эти дни. Дальше потоки по месяцам, дни занятий кружочками.

B · Указатель курсов

Каждый курс один раз, все его потоки рядом билетиками. Крупный поиск, разделы как в каталоге, порядок «ближайшие» или по алфавиту.

C · Фильтры и шкала

Слева панель: шкала месяцев, удобное время, документ, направление, стоимость. У каждого варианта видно, сколько потоков останется.

Общее для всех трёх

  • Строка вместо карточки, вся строка — ссылка. Справа белые стрелки на общей фиолетовой полосе панели.
  • Месяц — одна белая панель, а не россыпь карточек.
  • Статус показываем только когда он что-то значит: «Идёт набор» у всех — это не сигнал.
  • «Последний шанс» — донабор на курсы, которые уже начались, — первым блоком на тёплой подложке.
  • Мини-курсов в расписании нет — у них нет даты. Лист ожидания раскрыт, с бронью 5 000 ₽.
  • Скидка у цены: купон «−10 % | до 31 октября».
  • У цены — рассрочка, дни занятий — сокращениями под документом.
