# Основы нарративной практики — лендинг курса

Адрес превью: `preview.modern-psy.ru/narrative-therapy`. Собран 05.10.2026.

Обновление страницы `https://modern-psy.ru/narrative-therapy` по ТЗ «нарративная практика» (PDF от 05.10.2026).
Основа сборки и темы: `rodbt-record/` (компоненты Академии из `web-academy/shared/academy`).
Тексты, которые ТЗ велит «оставить как есть», перенесены со старой страницы дословно.

## Как править и собирать

| Что менять | Где |
| --- | --- |
| Тексты, цены, ссылки, картинки | `data/*.json` |
| Тема (`.narrative-therapy-page`), проектные блоки | `page.css` |
| Состав и порядок секций, проектные рендереры | `build.mjs` |
| Анимированные схемы ситуаций | `scenes.mjs` (рисунок), `page.css` раздел «Схемы ситуаций» (цвета и движение) |
| Вкладки и пауза анимаций вне экрана | `page.js` |

Из `apps/preview`:

```sh
node narrative-therapy/build.mjs          # data + page.css + shared/academy -> index.html, style.css, script.js
node narrative-therapy/build-tilda.mjs    # index.html -> tilda/*.html (по одной секции на T123), preview.html, manifest.json
```

`index.html`, `style.css`, `script.js` и `tilda/` генерируются, руками их не правят.

Три секции (принципы, чему научитесь, почему мы) рисует один проектный рендерер `card-set`.
Блок «Как работает специалист» рисует `renderAboutSteps` (из трёх вариантов 05.10.2026 выбран второй).

Блок «Где можно применять» пока в трёх вариантах с плашкой `variant-note`, у каждой из шести ситуаций своя
анимированная схема: проблема отходит от человека; от одной линии ответвляются новые истории; вокруг человека
появляются связи контекста; ступени опоры и подъём; мост через разрыв; к человеку присоединяется группа и общая история.
Цикл 7 секунд, анимируются только transform и opacity, вне экрана схема на паузе, при reduced motion видно итоговое состояние.
Остаться должен один вариант: лишние убрать из `sections` в `build.mjs` и из `titles` в `build-tilda.mjs`.

## Правки по ТЗ

- Название курса: «Основы нарративной практики» вместо «Основы нарративной терапии».
- Программа: из модуля 3 убран пункт «Нарративная практика при работе с травмой»; добавлен модуль 4
  «Дополнительный модуль. Расширение нарративной практики» с меткой «Входит в полный курс».
- «Чему вы научитесь»: последняя карточка называется «Использовать терапевтические документы», текст прежний.
- «Почему выбирают нас»: убран пункт «Супервизии по направлениям».
- Цена: два тарифа — «Первые три модуля» 35 000 ₽ и «Полный курс» 45 000 ₽.

## Цена

Блок статичный (`CMS_SLUG = null` в `build.mjs`), режим `plans`. В CMS курс `narrative-therapy` есть, но без тарифов:
одна цена 45 000 ₽ и поток 26 января 2027. Когда тарифы заведут в CMS, поставить `CMS_SLUG = 'narrative-therapy'`.

Тарифы (подтверждено 05.10.2026): «Первые три модуля» — 80 академ. часов, 12 недель; «Полный курс» — 112 академ. часов, 16 недель.
На первом экране это одна плитка с двумя тарифами рядом (`tariffs` в первой карточке `hero.json`, функция `withTariffCard` в `build.mjs`).

## Что ждём и что проверить

- «Для кого»: фото общее для лендингов Академии (`img-asp-for-whom.webp`). Если нужно своё, задать `image` в `audience.json`.
  Тексты карточек склеены в один абзац; у третьей убран повтор «Для специалистов помогающих профессий —».

- **Новая картинка для блока «Осваиваете подход через практику».** Сейчас стоит старая (группа в кругу).
- **Новые картинки для трёх карточек доказательной базы:** «Повышает надежду и даёт позитивный аффект»,
  «Эффективна при ПТСР и сложной травме», «Подходит для клиентов с онкологией». В `evidence.json` у них `"replace": true`,
  пока стоят старые.
- **Фото первого экрана.** Старое фото вертикальное (1012×1220): на телефоне ложится хорошо, а на планшете и десктопе
  героиня оказывается под заголовком. Нужна горизонтальная версия, где человек справа.
- Старт потока «26 января» взят из CMS (поток «Нарративная 26 января», 2027 год). В ТЗ даты нет.
- Marker нативной формы Тильды: в `lead-form.json` стоит `narrative-therapy`, подтвердить.
- Блоки старой страницы, которых нет в ТЗ, и на новой странице их нет: «С какими запросами работает нарративная практика»
  (восемь запросов), «Осваивайте нарративную практику шаг за шагом» (четыре блока с картинками), «Гибкие условия оплаты»
  (рассрочка, скидки, налоговый вычет) и скидки в блоке цены. Если какой-то нужен, вернуть.
- Пятого экрана в ТЗ нет: нумерация идёт с четвёртого сразу на шестой.

## Проверено локально 05.10.2026

Ширины 340, 375, 520, 768, 1024, 1440: без горизонтального скролла, консоль чистая, картинки грузятся с CDN Тильды.
Доставка заявок и нативная форма Тильды локально не проверяются. Все картинки по ссылкам `static.tildacdn.com`,
локальных файлов нет, поэтому `build-tilda.mjs` собирается без флага `--allow-local`.
