# Основы нарративной практики — лендинг курса

Адрес превью: `preview.modern-psy.ru/narrative-therapy`. Собран 05.10.2026.

Обновление страницы `https://modern-psy.ru/narrative-therapy` по ТЗ «нарративная практика» (PDF от 05.10.2026).
Основа сборки и темы: `rodbt-record/` (компоненты Академии из `web-academy/shared/academy`).
Тексты, которые ТЗ велит «оставить как есть», перенесены со старой страницы дословно.

## Как править и собирать

| Что менять | Где |
| --- | --- |
| Тексты, цены, ссылки, картинки | `data/*.json` |
| Тема (`.narrative-therapy-page`), проектные блоки | `page.css` |
| Состав и порядок секций, проектные рендереры | `build.mjs` |
| Анимированные схемы ситуаций | `scenes.mjs` (рисунок), `page.css` раздел «Схемы ситуаций» (цвета и движение) |
| Переключение модулей программы, лента доказательной базы, пауза анимаций вне экрана | `page.js` |

Из `apps/preview`:

```sh
node narrative-therapy/build.mjs          # data + page.css + shared/academy -> index.html, style.css, script.js
node narrative-therapy/build-tilda.mjs    # index.html -> tilda/*.html (по одной секции на T123), preview.html, manifest.json
```

`index.html`, `style.css`, `script.js` и `tilda/` генерируются, руками их не правят.

Блок «Где можно применять» (выбран третий вариант, нумерация убрана): у каждой из шести ситуаций своя

## Цена

Общий блок тарифов `pricing-render.mjs` из «Психолога-консультанта» (выбран 05.10.2026 из трёх вариантов). Данные —
`data/pricing.json`: два тарифа, полные цены 35 000 ₽ и 45 000 ₽, списки «входит / не входит». В CMS курс
`narrative-therapy` заведён одной ценой без тарифов, поэтому блок статичный. Общий блок требует цену в месяц, а у нас
подтверждены только полные цены: строка цены после сборки заменяется на полную цену. Строка «Можно оплатить в рассрочку»
закомментирована в HTML по просьбе пользователя; вернуть — `SHOW_INSTALLMENT = true` в `build.mjs`.

Соответствие часов и недель тарифам подтверждено 05.10.2026: три модуля — 80 ч, 12 недель; полный курс — 112 ч, 16 недель.

## SEO

По `docs/seo.md`, данные в `data/seo.json`; разметка строится из тех же данных, что и страница (аудит 06.10.2026).

- **title** «Основы нарративной практики — курс для психологов | АСП» (55 знаков), **description** 149 знаков.
- **canonical** и **og:url**: `https://modern-psy.ru/narrative-therapy`. Open Graph: type, site_name, locale, title, description, url.
- **JSON-LD**, три блока:
  - `EducationalOrganization` — реквизиты из подвала живой страницы modern-psy.ru;
  - `Course` с потоком 26 января 2027 (дата из CMS), преподавателем и двумя предложениями 35 000 ₽ и 45 000 ₽ из `data/pricing.json`;
  - `FAQPage` — вопросы и ответы дословно из `data/faq.json`.
  Цены и тексты сверены с видимым текстом страницы.
- **В превью** стоит `noindex,nofollow`: превью не должно попасть в поиск. В Тильду этот тег не переносится.

**В Тильде:** title, description, canonical и Open Graph задаются в настройках страницы («SEO» и «Соцсети»),
значения берутся из `data/seo.json`. JSON-LD — последний блок T123 `tilda/20-seo-jsonld.html`.

**⚠️ НЕТ ДАННЫХ:** картинка для соцсетей 1200×630 (`og:image`). Когда появится, заполнить `ogImage` в `data/seo.json`
(`{src, width, height}`): сборка сама добавит og:image и twitter:card.

## Что ждём и что проверить

- Картинка 1200×630 для соцсетей (`og:image`), см. раздел SEO.

- «Для кого»: фото общее для лендингов Академии (`img-asp-for-whom.webp`). Если нужно своё, задать `image` в `audience.json`.
  Тексты карточек склеены в один абзац; у третьей убран повтор «Для специалистов помогающих профессий —».

- **Ссылка на CDN для картинки блока «Осваиваете подход через практику».** С 05.10.2026 там руки с блокнотом на коленях
  из `rodbt-record` (блок «Первый уровень», `rodbt-record/assets/level.webp`), скопирована в `assets/practice.webp`.
  У файла нет CDN-ссылки и в `rodbt-record` — та же ссылка подойдёт обоим лендингам.

- **Ссылка на CDN для фото первого экрана.** С 05.10.2026 стоит новое широкое фото `assets/hero.webp` (2560×1087,
  «линия жизни на столе», из `Generations/38-narrative-hero/v2-lived-in/web/1-lifeline-table-shaded.webp`).
  Файл локальный: `build-tilda.mjs` без CDN-ссылки останавливается, флаг `--allow-local` только для проверки.
  Кадр по ширинам — переменные `--hero-subject-position-*` в `page.css`: 84% (до 520px: правая героиня целиком, левая на 340–375px
  у края кадра), 90% (521–767px, видны обе), 80% (768–1024px), right (от 1025px, текст на затемнённой левой части).
- Старт потока «26 января» взят из CMS (поток «Нарративная 26 января», 2027 год). В ТЗ даты нет.
- Marker нативной формы Тильды: в `lead-form.json` стоит `narrative-therapy`, подтвердить.
- Блоки старой страницы, которых нет в ТЗ, и на новой странице их нет: «С какими запросами работает нарративная практика»
  (восемь запросов), «Осваивайте нарративную практику шаг за шагом» (четыре блока с картинками), «Гибкие условия оплаты»
  (рассрочка, скидки, налоговый вычет) и скидки в блоке цены. Если какой-то нужен, вернуть.
- Пятого экрана в ТЗ нет: нумерация идёт с четвёртого сразу на шестой.

## Проверено локально 05.10.2026

Ширины 340, 375, 520, 768, 1024, 1440: без горизонтального скролла, консоль чистая, картинки грузятся с CDN Тильды.
Доставка заявок и нативная форма Тильды локально не проверяются. Все картинки по ссылкам `static.tildacdn.com`,
локальных файлов нет, поэтому `build-tilda.mjs` собирается без флага `--allow-local`.
