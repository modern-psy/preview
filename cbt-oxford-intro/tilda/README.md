# Блоки T123 — Знакомство с КПТ Оксфордская модель

Каждый пронумерованный HTML-файл целиком вставляется в отдельный T123.
Порядок сверху вниз — по номеру файла. У каждого T123 установите нулевые
верхний и нижний отступы: интервалы между секциями уже находятся в CSS.

| Файл | Содержимое |
| --- | --- |
| `00-styles.html` | Общие стили 1/2 и подключение шрифта |
| `01-styles.html` | Общие стили 2/2 и тема страницы |
| `02-hero.html` | Первый экран |
| `03-course-audience.html` | Кому подойдёт мини-курс |
| `04-outcomes.html` | После мини-курса вы сможете |
| `05-format.html` | Как устроен мини-курс |
| `06-learning.html` | Программа |
| `07-teachers.html` | Ведущие мини-курса |
| `08-grant-gift.html` | Грант на программу: «кладка» из подарочных карт. Внутри закомментирован прежний блок «Посмотрите все 4 урока…» — его можно вернуть, сняв комментарий |
| `09-lead-form.html` | Форма заявки |
| `10-academy-showcase.html` | Об Академии |
| `11-scripts.html` | intl-tel-input и общие скрипты |

Первые два блока содержат общие стили: они нужны один раз на странице,
CSS разделён на две части, чтобы каждый файл был меньше 65 000 символов.
Блок 11 содержит intl-tel-input и всю логику (схема «порочный круг», линия программы, вылет подарочных карт, форма заявки, сетка CTA для отключённого блока); его ставим последним, после всех секций и нативной формы Тильды.

Каждая секция имеет свою обёртку `academy-page cbt-oxford-intro-page`
с атрибутом `data-cbt-oxford-intro-part`: не удаляйте её, ID и служебные
`data-`атрибуты. Разметка не пересекает границы T123, скрипты сами находят
все секции и ждут готовности DOM.

## Что остаётся в Тильде

- Штатные шапка и подвал страницы.
- Нативная форма Тильды с `tildaspec-formname=mini-oxford`, полями Name,
  email, Phone, messenger-type (telegram / vk / max) и messenger-id,
  настроенными получателями. HTML-блок формы сам по себе заявки не отправляет: он
  заполняет нативную форму и жмёт её кнопку. Нативный блок ставится между
  секциями и блоком скриптов, скрипт его прячет.
- SEO-настройки и HEAD страницы; этот пакет их не заменяет.

## Проверка и дальнейшие правки

`preview.html` — локальная сборка всех блоков в обёртках, имитирующих T123;
её в Тильду не вставляем, `manifest.json` тоже служебный.

Контент правим в `../index.html`, стили в `../style.css`, логику в
`../script.js`, затем из корня репозитория:

```sh
python3 apps/preview/cbt-oxford-intro/build-tilda.py
```

Файлы этого каталога генерируются: ручные правки HTML затрутся при
пересборке.
