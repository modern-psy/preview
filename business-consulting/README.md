## Как править и собирать

| Что менять | Где |
| --- | --- |
| Тексты, ссылки, картинки | `data/*.json` |
| Тема (`.business-consulting-page`) и проектные блоки | `page.css` |
| Карточка цены и обновление из CMS, вкладки «Как вы будете учиться» | `page.js` |
| Анимированные схемы «Как вы будете учиться» | `scenes.mjs` |
| Состав и порядок секций | `build.mjs` |

Из `apps/preview`:

```sh
node business-consulting/build.mjs             # data + page.css + page.js + shared/academy -> index.html, style.css, script.js
node business-consulting/build.mjs --refresh   # то же, но снимок цены заново берётся из Public API
node business-consulting/build-tilda.mjs       # index.html -> tilda/*.html (по одной секции на T123), preview.html, manifest.json
```

`index.html`, `style.css`, `script.js` и `tilda/` генерируются, руками их не правят.

## Цена и расписание из CMS

Карточку цены рисует одна функция из `page.js` — при сборке (снимок `data/api-course.json`) и в браузере
(запрос к `https://modern-psy-asp-prod-8ceb.twc1.net/api/public/course/business-consulting`). Если цифры в API
другие, скрипт перерисовывает карточку, дату старта (`data-cms-start`: первый экран, программа, форма), расписание
(`data-cms-schedule-days` / `-time` в программе; разбирается из поля потока «По средам 18:00–21:00»; в первом экране
дней и времени больше нет — там плитка старта и под кнопкой «Обучение онлайн») и цену в JSON-LD.
API не ответил — остаётся снимок. На 12.10.2026: 36 000 ₽ вместо 40 000 ₽ (курс месяца −10 % до 31 октября),
рассрочка 1 500 ₽/мес (цена ÷ 24, как в каталоге). После 31 октября пересобрать с `--refresh`, чтобы снимок
и микроразметка без скрипта тоже показывали 40 000 ₽.

## Что сделать в CMS (правка 1: название везде)

Каталог, шапка и календарь берут название из CMS, поэтому переименование делается там:

1. Курс `business-consulting` → поле «Название» (title): «Корпоративное консультирование для психологов».
   Если заполнено поле «Название в каталоге» (catalog_title) — поменять и его.
2. Поток «Бизнес-консультирование 18 ноября» → подпись (label): «Корпоративное консультирование 18 ноября».
3. После сохранения пересобрать снимки для поисковиков: `node apps/tilda/catalog-live/build.mjs`
   и `node apps/tilda/header/build.mjs`, перевставить блоки каталога (/courses, /specializations) и шапки.
   Баннер «Курсы месяца» (`apps/tilda/course-month`) тоже держит снимок со старым названием.
4. В Тильде у страницы поменять заголовок, description и og:title (тексты — `data/seo.json`).
