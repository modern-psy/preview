# Фоновая графика баннера

Шесть картинок: для каждого брейкпоинта левая и правая. Вырезаны из PDF-макетов
Figma, текст с них снят — надписи в баннере живые, HTML.

Файлы в @2x (ретина). В CSS каждая выводится вдвое меньше — размер задан
жёстко в `--pb-bg-*-size`, менять его при заливке на сервер не нужно.

| Файл | Пиксели (@2x) | Показывается как | Прижата к | Переменная в CSS |
|---|---|---|---|---|
| `banner-desktop-left.webp`  | 1400×200 | 700×100 | левому краю  | `--pb-bg-left`  в блоке «ДЕСКТОП» |
| `banner-desktop-right.webp` | 1480×200 | 740×100 | правому краю | `--pb-bg-right` в блоке «ДЕСКТОП» |
| `banner-tablet-left.webp`   | 1050×140 | 525×70  | левому краю  | `--pb-bg-left`  в блоке «ПЛАНШЕТ» |
| `banner-tablet-right.webp`  | 610×140  | 305×70  | правому краю | `--pb-bg-right` в блоке «ПЛАНШЕТ» |
| `banner-mobile-left.webp`   | 340×105  | 170×52  | левому краю  | `--pb-bg-left`  базовый блок |
| `banner-mobile-right.webp`  | 544×105  | 272×52  | правому краю | `--pb-bg-right` базовый блок |

Всего ~83 КБ.

## Где лежат сейчас

Залиты на `s3.twcstorage.ru/asp-media/`, эти адреса прописаны в CSS баннера.
Хранилище пережало файлы примерно на 3 % — размеры кадров и прозрачность
сохранились, разница с исходниками на глаз неразличима (PSNR ≈ 45 дБ).

## Важно про формат

WebP, и это не случайность: у картинок прозрачные внутренние края — именно за
счёт них левая и правая половины незаметно растворяются в ровной заливке
`--pb-bg`, и стык не виден ни на какой ширине экрана. JPEG прозрачность
не умеет, PNG весит втрое больше. При перезаливке не пережимать
и не конвертировать — как есть.
