# Публичная оферта

Локальная HTML-страница. Источник: https://modern-psy.ru/oferta (12 октября 2026).
Полный текст, таблицы, приложения и сканы подписей сохранены.

Композиция документа: `offer_group`, `offer_table`, `offer_table-scroll`, `offer_signature`. Типографика — общие `body-text` и `section-heading` Web Academy; структура и ссылки — корневая дизайн-система. Общие CSS встроены в `style.css`, runtime-ссылок на библиотеку нет. Основной текст использует `is-reading is-regular` и основной цвет для контраста.

Запуск из apps/preview: `python3 -m http.server 8841 --bind 127.0.0.1`.
Открыть http://127.0.0.1:8841/oferta/. JavaScript не нужен.
Шрифт загружается с Google Fonts, сканы сохранены локально в assets/ с исходных URL Tilda CDN.
Не опубликовано; коммит и пуш не выполнялись.

Правки: белый фон, ссылка без UTM, увеличенные отступы разделов. До 768px таблицы перестраиваются в вертикальные блоки с подписями полей; разметка и данные единые для всех ширин.

От 768px, включая десктоп: программы в карточках, название на всю ширину, остальные четыре поля в двух колонках; мобильная композиция сохранена.
