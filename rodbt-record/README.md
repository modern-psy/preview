# Первый уровень РО ДБТ — лендинг курса в записи с Томасом Линчем

Адрес превью: `preview.modern-psy.ru/rodbt-record`. Собран 02.10.2026.

Основа: лендинг живого курса `rodbt-live/` (те же блоки, тема и сборка). Контент перенесён
со страницы `https://modern-psy.ru/rodbt` в состоянии на 02.10.2026 с тремя правками пользователя:

1. Тренер один: Томас Линч. Блок «Дополнительные тренеры» убран, Люк Джордан заменён.
2. Вместо живого формата везде записи: нет дат, Zoom и синхронного перевода.
3. Цена 30 000 ₽, одна, без повышения.

Соседние папки `rodbt-live/` (живой курс) и `rodbt/` (прежняя версия курса в записи) не трогали.

## Как править и собирать

| Что менять | Где |
| --- | --- |
| Тексты, цена, ссылки, картинки | `data/*.json` |
| Тема (`.rodbt-record-page`), проектные блоки | `page.css` |
| Состав и порядок секций, проектные рендереры | `build.mjs` |
| Скрипт разделов навыков и программы | `page.js` |

Из `apps/preview`:

```sh
node rodbt-record/build.mjs          # data + page.css + shared/academy -> index.html, style.css, script.js
node rodbt-record/build-tilda.mjs    # index.html -> tilda/*.html (по одной секции на T123), preview.html, manifest.json
```

`index.html`, `style.css`, `script.js` и `tilda/` генерируются, руками их не правят.

## Цена

`data/course.json`: 30 000 ₽, поток без даты с названием «Курс в записи». Блок статичный
(`CMS_SLUG = null` в `build.mjs`): слаг `rodbt-lvl1` в CMS сейчас отдаёт поток с датами живого курса.

## Где текст отличается от страницы-источника

На странице смешаны живой курс и записи, поэтому часть формулировок заменена. Их нужно вычитать.

- Биография Томаса Линча взята из `rodbt/data/instructor.json` (версия той же страницы от 17.09.2026):
  на текущей странице инструктором стоит Люк Джордан.
- Плитка «16 академ. часов»: убрано «Интенсивная двухдневная программа».
- «Метод из первых рук»: вместо Джулианны Гордер текст про Томаса Линча из плитки первого экрана.
- «Синхронный перевод и материалы на русском» заменено на «Русские субтитры и материалы на русском»
  с текстом плитки «Языковая поддержка».
- «Как вы будете учиться», шаг 1: вместо «Живой формат» текст про шесть записанных лекций из `rodbt/`.
  Шаг 3: вместо «После интенсива у вас будет 30 дней…» текст по ответу из FAQ (доступ бессрочный).
- «Первый уровень»: «уже после интенсива» заменено на «уже после курса».
- Блок цены и заголовок формы: вместо «Оплатите заранее и сэкономьте» и «Занятия начнутся 26 ноября»
  нейтральные строки про записи («Лекции доступны сразу после оплаты»).
- Документы: два шага получения составлены по тексту про тесты и ответу FAQ.
- Опечатки источника исправлены: «Radically Ope Institute», «чек-листов», прямые кавычки.
