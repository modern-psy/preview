# apps/preview — страницы на согласовании

Здесь живут черновики лендингов. Они открываются на отдельном поддомене
(`preview.modern-psy.ru`), закрыты от поисковиков и на боевом сайте их нет.

## Как устроены адреса

Так же, как на боевом сайте: папка = адрес.

| Где лежит файл             | Какой адрес получится                      |
|----------------------------|--------------------------------------------|
| `index.html`               | `/` — оглавление всех превью               |
| `emdr/index.html`          | `preview.modern-psy.ru/emdr`               |
| `novyy-kurs/index.html`    | `preview.modern-psy.ru/novyy-kurs`         |

## Инфраструктура новых лендингов

- `AGENTS.md` — общие правила работ внутри preview-контура;
- `web-academy/` — исходные проекты, токены, правила и инструменты Web Academy;
- `site-components/` — библиотека компонентов для повторного использования.

Эти каталоги не являются готовыми лендингами и не добавляются в оглавление
превью. Новая страница по-прежнему получает собственную соседнюю папку
`apps/preview/<slug>/` и остаётся самодостаточной.

## Куда пушить вёрстку

Вёрстка лендингов пушится **только** в репозиторий
[modern-psy/preview](https://github.com/modern-psy/preview), ветка `main`.
Папка `apps/preview/` — это и есть его рабочая копия (свой `.git`, `origin`
смотрит на `modern-psy/preview`). Timeweb App Platform собирает превью
прямо из этого репозитория.

- Коммит и пуш делаются из папки `apps/preview/`, а не из корня `asp-deploy`.
- Никуда больше вёрстку не пушить: ни в `asp-deploy`, ни в `ASP-Prod`,
  ни в личные репозитории.
- Видео (`*.mp4`) в репозиторий не кладём — они в `.gitignore`.

## Как добавить страницу на согласование

1. Создайте папку с именем будущего лендинга (латиницей, через дефис).
2. Положите внутрь вёрстку: `index.html` и её файлы.
3. Загрузите папку в GitHub — только в репозиторий
   [modern-psy/preview](https://github.com/modern-psy/preview), ветка `main`.
4. Через 1–2 минуты откроется по адресу `preview.modern-psy.ru/имя-папки`.
5. По желанию добавьте ссылку в оглавление — файл `index.html` в этой папке,
   там есть готовый образец блока со ссылкой.

## Как перенести согласованную страницу на боевой сайт

В GitHub перетащите ту же папку в `apps/site` (или загрузите её туда заново).
Адрес станет `modern-psy.ru/имя-папки`.

Старую копию в `apps/preview` можно удалить — но не обязательно, она никому
не мешает и не индексируется.

## Важно

Каждая папка со страницей должна быть самодостаточной: её стили, скрипты
и картинки лежат внутри неё же. Тогда страница переезжает из превью в прод
простым перетаскиванием папки, и ничего не ломается.
