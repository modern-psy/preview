# ACT · сборка для Тильды

Сборка: `node apps/preview/act/build-tilda.mjs`. Исходники — web-academy/projects/act. Файлы этой папки вручную не править.

1. В HEAD страницы добавить head.html. Метатеги и аналитику оставить. styles-1.html, styles-2.html, styles-3.html вставить отдельными T123 перед Hero, в указанном порядке, с нулевыми внешними полями. Общие стили разбиты с учётом лимита одного поля кода.
2. Заменить содержательные старые секции файлами 01-body-hero.html … 16-body-faq.html: один файл — один T123. Внешние поля сверху/снизу у каждого T123 поставить 0. Хедер и футер сайта сохранить.
3. Цены стоят над формой; условия оплаты и скидки — под формой. Отдельный блок двух рассрочек не переносится.
4. Сохранить нативную форму ACT (подробности в FORM-TILDA.md) после 14-body-lead.html. Перед публикацией добавить в неё поле электронной почты с именем Email. Не удалять получателей и CAPTCHA.
5. Сохранить существующий попап бесплатных лекций #free-lessons-act и его нативную форму. Кнопка «Получить доступ» открывает этот попап; Hero прокручивает к #act-trial и #act-program.
6. После всех BODY и нативной формы вставить один раз: footer-cms.html, footer-components.html, footer-course.html, footer-form.html в этом порядке. Старые скрипты ранее вставленных Hero/цен удалить, чтобы CMS не запускалась дважды.
7. Старый ANNEXX/Нолим T123 rec781266852 (3SzwvUWF), который дублировал диплом, отключить.

## Проверка до публикации

preview.html собран из этих же HEAD, STYLE, BODY и FOOTER. fixture.html дополнительно имитирует стили и нативные события Тильды: реальные заявки он не отправляет. Все 15 секций отдельные; SVG встроены, фото на постоянном Tilda CDN, Wix — Google Fonts, intl-tel-input — 29.1.2. Hero и цены используют Public API с резервным снимком. Manifest содержит SHA-256 и размеры каждого фрагмента; каждый HTML меньше 65 000 символов.

## Проверка после публикации

Убедиться, что видна одна кастомная форма, а нативный блок с marker act скрыт и остаётся в DOM. Проверить обе ветки MAX/Telegram, CAPTCHA и фактическое поступление тестовых заявок в CRM. Только matching tildaform:aftersuccess показывает успех. Локальный стенд не подтверждает доставку. Проверить оба потока, обе CTA, бесплатный попап, видео, преподавателей и FAQ.
