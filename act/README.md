# ACT · локальный лендинг

- [Лендинг целиком](http://127.0.0.1:8765/act/)
- [Все 16 секций по отдельности](http://127.0.0.1:8765/act/sections/)
- Исходники: `apps/preview/web-academy/projects/act/`.

Пересобрать:

```sh
node apps/preview/act/build.mjs
```

Содержание и композиции сняты с modern-psy.ru/act 13.10.2026. Сохранены изображения, 14 видео Kinescope, 8 преподавателей, 11 отзывов, все темы программы и 6 ответов FAQ. Палитра и Wix Madefor Text — Academy. Hero и цены используются из согласованной версии. Форма заявки заменена готовым блоком Academy с его адаптивом, выбором страны и MAX / Telegram; [отдельный просмотр формы](http://127.0.0.1:8765/act/sections/14-lead.html).

Форма и окно бесплатного доступа локально проверяют поля; заявки не отправляются. После нажатия «Отправить» явно показывается статус предпросмотра. Транспорт нативной Тильды/CRM подключается после согласования.

Папка `tilda/` содержит актуальную сборку всех 16 секций: каждый блок отдельным BODY/T123, общие стили и скрипты — отдельными файлами. Сборка: `node apps/preview/act/build-tilda.mjs`. Порядок вставки — `tilda/README.md`, подключение нативной формы — `tilda/FORM-TILDA.md`. Перед публикацией добавить Email в существующий нативный блок ACT.

FAQ также использует готовый блок Academy с шестью исходными вопросами и ответами. [Отдельный просмотр FAQ](http://127.0.0.1:8765/act/sections/16-faq.html). Порядок нижних блоков: цены → форма → условия оплаты и скидки → FAQ.
