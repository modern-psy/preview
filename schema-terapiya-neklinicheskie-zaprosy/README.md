Адрес превью: https://modern-psy-preview-5a99.twc1.net/schema-terapiya-neklinicheskie-zaprosy/ . Живая страница:
https://modern-psy.ru/schema-terapiya-neklinicheskie-zaprosy (адрес и слаг в CMS не меняются, меняется название).

Собран 15.10.2026: перевёрстка живой страницы на блоках библиотеки Академии (`web-academy/shared/academy` и галерея блоков).
Блоки, которые есть в библиотеке, взяты оттуда; недостающие проектируются по одному через /impeccable (три макета, выбор, вёрстка).

## Как править и собирать

| Что менять | Где |
| --- | --- |
| Тексты, ссылки, картинки | `data/*.json` |
| Тема (`.schema-terapiya-neklinicheskie-zaprosy-page`) и проектные блоки | `page.css` |
| Обновление старта, часов и цены из CMS в браузере | `cms.js` |
| Состав и порядок секций | `build.mjs` |

Из `apps/preview`:

```sh
node schema-terapiya-neklinicheskie-zaprosy/build.mjs             # data + page.css + shared/academy -> index.html, style.css, script.js
node schema-terapiya-neklinicheskie-zaprosy/build.mjs --refresh   # то же, но снимок цены, старта и часов заново из Public API
node schema-terapiya-neklinicheskie-zaprosy/build-tilda.mjs       # index.html -> tilda/*.html (по одной секции на T123), preview.html, manifest.json
```

`index.html`, `style.css`, `script.js` и `tilda/` генерируются, руками их не правят. После любой правки — обе команды по очереди.

## Перенос в Тильду (пакет `tilda/`, собран 16.10.2026)

18 блоков T123, каждый меньше 65 000 символов; локальных картинок нет (все фото на static.tildacdn.com и S3, иллюстрация
первого экрана нарисована кодом). Проверка всего пакета вместе — `tilda/preview.html`.

1. На странице выключить штатные шапку и подвал Тильды, если они мешают (шапка сайта из CMS остаётся).
2. Вставить блоки T123 строго по порядку номеров, у каждого отступы сверху и снизу 0:
   `00`–`02` — общие стили; `03`–`14` — двенадцать секций; `15`–`16` — общие скрипты (после секций и нативной формы); `17` — микроразметка.
3. Нативная форма Тильды должна стоять на странице (её скрывает наша форма и отправляет в неё заявки). Наша форма ищет её
   по имени `tildaspec-formname`, сейчас `schema-terapiya-neklinicheskie-zaprosy` (`data/lead-form.json` → `nativeMarker`).
   **На нынешней живой странице форма называется `womens-care`** — похоже, скопирована с другой страницы. Либо переименовать
   форму в Тильде в `schema-terapiya-neklinicheskie-zaprosy`, либо вписать её реальное имя в `nativeMarker` и пересобрать.
4. В настройках страницы: заголовок, description и og:title — из `data/seo.json`; og:image — когда будет картинка с новым названием.
5. Старые блоки страницы (T123 с секциями и Zero-блоки старой версии) скрыть, а не удалять — пока новая версия не проверена.

## CMS

Старт, часы и цена берутся из CMS (снимки `data/api-course.json`, `data/api-catalog-entry.json`; в браузере `cms.js`).
На 15.10.2026: поток 10 ноября, по вторникам 18:00–20:00, 45 000 ₽, рассрочка 1 875 ₽/мес (÷ 24), 52 академических часа.

Название в CMS пока старое («Схема-терапия для неклинических запросов»), поэтому на странице оно из API не подставляется:
новое вшито из `data/pricing.json` → `title`. После переименования курса в CMS пересобрать снимки каталога и шапки
(`apps/tilda/catalog-live`, `apps/tilda/header`), как это делалось для /business-consulting.

## Что ждём

- Минорные правки контента от Дарьи.
- «Продолжительность» курса в месяцах неизвестна, поэтому в фактах первого экрана вместо неё «Занятия: по вторникам».
- Имя формы Тильды: сейчас `nativeMarker` = `schema-terapiya-neklinicheskie-zaprosy`, а на живой странице форма называется `womens-care` (см. «Перенос в Тильду», п. 3).
- og:image 1200 × 630 с новым названием (старая картинка страницы, скорее всего, со старым).
- Фото: все со старой страницы (static.tildacdn.com, png 350–640 КБ). Для скорости лучше webp на S3.
  Фото «Что вы получаете» — постановочное, с улыбками; если нужно репортажное, заменить.
- FAQ про рассрочку говорит «от банков и Академии», а утверждённые «Гибкие условия оплаты» — только про банки. Ответ оставлен как на старой странице.
