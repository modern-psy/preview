Блоки, которые есть в библиотеке, взяты оттуда; недостающие проектируются по одному через /impeccable (три макета, выбор, вёрстка).

## Как править и собирать

| Что менять | Где |
| --- | --- |
| Тексты, ссылки, картинки | `data/*.json` |
| Тема (`.schema-terapiya-neklinicheskie-zaprosy-page`) и проектные блоки | `page.css` |
| Обновление старта, часов и цены из CMS в браузере | `cms.js` |
| Состав и порядок секций | `build.mjs` |

Из `apps/preview`:

```sh
node schema-terapiya-neklinicheskie-zaprosy/build.mjs             # data + page.css + shared/academy -> index.html, style.css, script.js
node schema-terapiya-neklinicheskie-zaprosy/build.mjs --refresh   # то же, но снимок цены, старта и часов заново из Public API
```

`index.html`, `style.css`, `script.js` генерируются, руками их не правят. Сборщика пакета Тильды пока нет: соберём после правок контента.

## CMS

Старт, часы и цена берутся из CMS (снимки `data/api-course.json`, `data/api-catalog-entry.json`; в браузере `cms.js`).
На 15.10.2026: поток 10 ноября, по вторникам 18:00–20:00, 45 000 ₽, рассрочка 1 875 ₽/мес (÷ 24), 52 академических часа.

Название в CMS пока старое («Схема-терапия для неклинических запросов»), поэтому на странице оно из API не подставляется:
новое вшито из `data/pricing.json` → `title`. После переименования курса в CMS пересобрать снимки каталога и шапки
(`apps/tilda/catalog-live`, `apps/tilda/header`), как это делалось для /business-consulting.

## Что ждём

- Минорные правки контента от Дарьи.
- «Продолжительность» курса в месяцах неизвестна, поэтому в фактах первого экрана вместо неё «Занятия: по вторникам».
- Имя формы Тильды (сейчас `nativeMarker` = `schema-terapiya-neklinicheskie-zaprosy`).
- og:image 1200 × 630 с новым названием (старая картинка страницы, скорее всего, со старым).
- Фото: все со старой страницы (static.tildacdn.com, png 350–640 КБ). Для скорости лучше webp на S3.
  Фото «Что вы получаете» — постановочное, с улыбками; если нужно репортажное, заменить.
- FAQ про рассрочку говорит «от банков и Академии», а утверждённые «Гибкие условия оплаты» — только про банки. Ответ оставлен как на старой странице.
