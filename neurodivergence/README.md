# Психотерапия нейроотличных клиентов: РАС и СДВГ

Лендинг курса повышения квалификации, живая страница — https://modern-psy.ru/neurodivergence
(сейчас собрана в Тильде из Zero-блоков на шрифте Gilroy).

26.10.2026 пересобрана кодом по просьбе Дарьи: состав и порядок блоков как на живой странице, тексты оттуда,
вид в мире Web Academy по образцу «Психиатрии для психологов». Что поменялось по задаче:

- преподаватели: добавлена Марина Овечкина (фото и описание как на «Клинической психологии»), убран ассистент
  Шахнишин Шукюров. Конофальская и Емельянов остались;
- шрифт Wix Madefor и роли текста из общих стилей лендингов v1 (`apps/preview/academy-base`, метка `data-academy="1"`);
- форма заявки — общий компонент `request-form`, режим «курс»: имя, телефон, Telegram (с ником) или MAX, без почты.
  На сайте заявка уходит через нативную форму Тильды `neurodivergence`, которая уже стоит на странице;
- блок цены — генератор `/pricing` (цены, повышения и рассрочка из CMS), раскладка `wa-narrow`.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Разметка и тексты. Править прямо здесь, кроме формы и блока цены. |
| `page.css`, `page.js` | Стили и поведение страницы (дата старта и часы из CMS, FAQ, номер посетителя Метрики для формы). |
| `academy.css` | Стили «Почему выбирают нас» и «98 % студентов», копия с «Психиатрии». |
| `request-form-sync.mjs` | Кладёт форму заявки: копии `request-form.css/js` и разметку между метками `request-form`. Тексты формы — в нём. |
| `price-sync.mjs` | Кладёт блок цены и микроразметку курса из свежих цен CMS между метками `price` и `price-ld`. Нужна папка `apps/preview/pricing` (есть только локально). |
| `build-tilda.mjs` | Собирает пакет T123 для Тильды в `tilda/` (перед ним запустить `price-sync.mjs`). |

Из `apps/preview`:

```sh
node neurodivergence/request-form-sync.mjs
node neurodivergence/price-sync.mjs
```

   на телефоне фото полосой сверху без растворения, старт и кнопка сразу под заголовком.

15. FAQ — семь вопросов со старой страницы, тексты дублируются в FAQPage внизу `index.html`.

## Правки текстов против живой страницы

- длинные тире убраны («Короткие блоки — легко удерживать внимание» → заголовок и подпись, «Ведущие — нейроотличные
  специалисты» → «Курс ведут нейроотличные специалисты», «70% занятий — практика» → «Практика занимает 70 % занятий»);
- опечатки: «нероотличный», «Нейротличные», «Фармако — и», «инд терапия», «с сдвг», «СПБГУ»;
- FAQ про рассрочку: как в блоке цены (до 24 месяцев от банков-партнёров), без «рассрочки от Академии»;
- кнопка первого экрана «Оставить заявку» ведёт к форме на странице, попап «Записаться на обучение» с почтой не нужен.

## Что берётся из CMS

- цены, повышения и рассрочка — блок цены (генератор /pricing);
- дата старта (первый экран и заголовок формы) — `page.js` из ближайшего потока курса, часы — из каталога
  (`/api/public/catalog`), метки `data-cms` в разметке. Если API не ответил, остаются тексты страницы.
