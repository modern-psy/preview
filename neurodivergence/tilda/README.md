# Психотерапия нейроотличных клиентов: блоки T123 для Тильды

Страница: https://modern-psy.ru/neurodivergence (сейчас на Zero-блоках).
Блоки собирает `build-tilda.mjs` из `index.html`, `page.css`, `page.js`, `academy.css` и копий формы заявки.
Файлы `NN-*.html`, `preview.html` и `manifest.json` руками не править: при следующей сборке они перезапишутся.
Правим исходники и пересобираем из `apps/preview`:

```sh
node neurodivergence/price-sync.mjs
node neurodivergence/build-tilda.mjs
```

`preview.html` — все блоки в обёртках, как их рисует Тильда, вместе с правилом ссылок из custom.css сайта.
Открывать через локальный сервер (общие стили v1 подключены по относительной ссылке). Все картинки с CDN
(static.tildacdn.com и S3). Высоты секций в `preview.html` совпадают с превью страницы на 375, 768 и 1440 px.

## Общие стили v1

Шрифт Wix Madefor, H1, кнопки и роли текста приходят из custom.css сайта (вставка «общие стили лендингов»).
В пакете их нет. У обёртки каждого блока метка `data-academy="1"`: без неё блок останется на старой типографике.
В head страницы можно поставить предзагрузку шрифта (настройки страницы, одна строка):
`<link rel="preload" href="https://static.tildacdn.com/tild3036-3463-4533-b066-643263323666/wix-madefor-text-aca.woff2" as="font" type="font/woff2" crossorigin>`

## Как вставить

Каждый файл в отдельный блок T123, по порядку номеров, сразу после блока шапки сайта. У всех T123 отступы сверху и снизу 0.

| Блок | Что внутри |
|---|---|
| 00-styles | все стили страницы, первый блок |
| 01-hero … 13-ratings | секции лендинга, каждая в своём T123. `12-academy` несёт стили «Почему выбирают нас» и «98 % студентов», `13-ratings` без него не работает |
| 14-price | блок цены из CMS (генератор /pricing, курс neurodivergence): цены, повышения, рассрочка и «Гибкие условия оплаты» |
| 15-signup | форма заявки (общий компонент request-form) со своими стилями |
| 16-faq | ответы на вопросы |
| 17-scripts | скрипт страницы: дата старта и часы из CMS, FAQ, номер посетителя Метрики для формы |
| 18-request-form | скрипт формы заявки, сразу после 17-scripts |
| 19-seo | микроразметка курса (её потоки и цены обновляет блок цены) и FAQ, в конце страницы |

**Блок нативной формы Тильды `neurodivergence` (rec1157785121, «Занятия начнутся…») перенести между `16-faq` и `17-scripts`.**
Скрипт формы прячет его и отправляет заявку через него.

## Форма заявки

Общий компонент Академии `request-form`, режим «курс», такой же, как на «Психиатрии для психологов»
(скрипт и стили совпадают байт в байт). Имя, телефон с маской Тильды, Telegram с ником или MAX, без почты.
Тексты формы и имя нативной формы — в `request-form-sync.mjs`.

- **Имя формы** в настройках блока Тильды: `neurodivergence` (так она называется на странице сейчас).
- **Поля нативной формы:** `Name`, `Phone`, блок мессенджеров (`messenger-type`, `messenger-id`). Почты в ней нет, это правильно.
- ⚠️ **Варианты мессенджера** в нативной форме сейчас `whatsapp` и `telegram`, варианта MAX нет. Компонент положит
  выбор MAX в слот `whatsapp`, и в amoCRM он придёт как WhatsApp. Лучше в настройках формы заменить WhatsApp
  на MAX (значение `max_messenger`), как на «Клинической психологии».
- Скрытыми скрипт добавляет `form_source` с устройством через « · » и `ym_client_id` из куки Метрики.
- На превью нативной формы нет: после проверки полей форма показывает «Отправка сейчас недоступна» и кнопку бота.

## Что берётся из CMS

- Цены, повышения и рассрочка — блок цены (`14-price`) при каждой загрузке; снимок цен в блоке на момент сборки.
- Дата старта («Старт 23 января» в первом экране, «Занятия начнутся 23 января» в форме) — `17-scripts`
  из ближайшего потока курса, часы («80 академических часов» в первом экране) — из каталога.
  Если API не ответил, остаются тексты из блоков.
- Не из CMS: «80 академических часов» в списке «Что входит» блока цены (пункты генератора, PAGES.neurodivergence),
  время занятий в программе, тексты страницы.

## Настройки страницы

Не менять: title, description, og:image и адрес остаются как сейчас на странице.
Если на странице в head есть своя разметка курса (Course), её убрать: курс размечает `19-seo`.

## Проверить после публикации

1. Кнопки «Оставить заявку» и «Получить доступ» видны (цвет текста ссылок-кнопок).
2. «Получить доступ» открывает попап бесплатных лекций.
3. Тестовая заявка (Telegram и MAX) дошла до amoCRM с именем, телефоном, мессенджером и form_source.
4. Якоря #signup и #free-lessons ведут в нужные блоки, заголовок программы на компьютере закреплён при прокрутке.
