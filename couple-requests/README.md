## Что берётся из CMS

| Что | Откуда | Где на странице |
|---|---|---|
| Набор или лист ожидания, дата старта | `/api/public/catalog`, карточка `couple-requests`: `mode`, `startDate` | строка над кнопкой первого экрана (`data-cms="start"`), заголовок формы (`data-cms="enrollment-start"`) |
| Часы | каталог: `hours` | первый факт под первым экраном (`data-cms="hours"`) |
| Время занятий | `/api/public/course/couple-requests`: `schedule` продаваемого потока, иначе ближайшего | факт «Онлайн» (`data-cms="schedule"`), подзаголовок программы (`data-cms="schedule-sentence"`) |
| Цены, повышения, бронь, рассрочка | курс в CMS, блок генератора /pricing | блок цены `#price`, микроразметка Course |

Утром 07.11.2026 в CMS был один поток — 8 октября 2026, статус «Лист ожидания». Днём Дарья завела новый: 25 марта 2027,
«По четвергам 18:30–20:30», «Идёт набор», 25 000 ₽, курс — 35 часов. Страница переключилась сама; текст в разметке
(виден, пока CMS не ответила) и снимок блока цены сверены с этими данными. Когда поток снова уйдёт в лист ожидания,
страница сама покажет «Запись в лист ожидания». Если API не ответил, остаётся текст из разметки.
