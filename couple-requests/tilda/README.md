# Работа с темой отношений в практике психолога: блоки T123 для Тильды

Страница: https://modern-psy.ru/couple-requests.
Блоки собирает `build-tilda.mjs` из `index.html`, `page.css`, `page.js`, `academy.css`, `diploma.css` и копий формы заявки.
Файлы `NN-*.html`, `preview.html` и `manifest.json` руками не править: при следующей сборке они перезапишутся.
Правим исходники и пересобираем из `apps/preview`:

```sh
node couple-requests/price-sync.mjs
node couple-requests/build-tilda.mjs
```

`preview.html` — все блоки в обёртках, как их рисует Тильда, вместе с правилом ссылок из custom.css сайта.
Открывать через локальный сервер (общие стили v1 подключены по относительной ссылке). Все картинки с CDN
(static.tildacdn.com, optim.tildacdn.com и S3 asp-media). Высоты блоков в `preview.html` совпадают с превью
лендинга на 375, 768 и 1440 px (проверено 07.11.2026).

## Общие стили v1

Шрифт Wix Madefor, H1, кнопки и роли текста приходят из custom.css сайта (вставка «общие стили лендингов»).
В пакете их нет. Каждый блок обёрнут в `main-wrapper academy-page couple-requests-page` с меткой `data-academy="1"`:
без неё блок останется на старой типографике.

## Перед публикацией

- Сверить тексты с живой страницей: если Дарья правила их в Тильде после 07.11.2026, перенести в `index.html`.
- После скрытия `rec2321644751` проверить шапку и подвал: в нём лежали глобальные переменные `:root` старой системы.
- og-картинки у страницы нет: загрузить руками в настройках страницы.
- Публикует Дарья.
