# Главная для Тильды: пакет блоков T123

Собирается из `apps/preview`:

```sh
node glavnaya/build.mjs          # превью и данные из каталога CMS
node glavnaya/build-tilda.mjs    # пакет для Тильды (только когда все картинки на S3)
node glavnaya/build-tilda.mjs --allow-local   # проверочный пакет, пока картинок на S3 нет
```

Файлы в этой папке руками не править: при следующей сборке они перезапишутся. Тексты правятся в
`glavnaya/template.html`, стили в `page.css`, поведение в `page.js`, данные в `glavnaya/data/`.

## Порядок блоков на странице

Все блоки — T123 «HTML-код», отступы сверху и снизу 0.

| Блок | Что внутри |
|---|---|
| 00-styles-1 | шрифт, типографика, стили разделов 0–5 |
| 01-styles-2 | стили разделов 6–10, наведение, поправки цветов ссылок под custom.css сайта |
| 02-hero … 11-pick | секции главной по порядку |
| **форма Тильды** | нативная форма (шаблон 1040_0) сразу после 11-pick, её не видно: заявку в неё кладёт скрипт |
| 12-scripts | скрипт страницы: табы, видео, лента отзывов, форма, свежие данные каталога |
| 13-seo | микроразметка: организация и сайт |

Шапку сайта в пакет не кладём: она подключается отдельной страницей-шапкой (`apps/tilda/header`).
Штатные шапку и подвал Тильды на странице не отключать.

## Форма «Поможем подобрать программу»

- Имя нативной формы Тильды: `mainpage` (в `template.html`, атрибут `data-tilda-form-name`). Форму в Тильде
  назвать так же, иначе заявка не уйдёт: покажется сообщение об ошибке со ссылкой на бота в Telegram.
- Поля, которые заполняет скрипт (если в форме их нет, он добавит скрытыми):
  `Name`, `Phone`, `messenger`, `messenger_contact`, `form_source`, `ym_client_id`, `utm_source`, `utm_medium`,
  `utm_campaign`, `utm_content`, `utm_term`. В `form_source` уходит «главная: подбор программы, <выбранный ответ>».

## Картинки

Все картинки главной лежат на S3 (две партии, 16.11.2026), карта «локальный путь → ссылка» в `glavnaya/data/assets.json`.
Новая картинка: положить в `glavnaya/img/`, загрузить на S3 через медиатеку CMS, вписать ссылку в `assets.json`
и пересобрать. Сборка без `--allow-local` остановится, если хоть одной ссылки не хватает. В проверочном пакете
(`--allow-local`) картинки берутся с превью modern-psy-preview-5a99.twc1.net, в Тильду такой пакет не загружать.

Картинки уменьшены под место на странице ×2 (правила Safari, раздел 3). Миниатюры курсов из каталога берут копию
`thumbnail_`, которую CMS делает сама (`s3Size` в page.js), фото Петроченко и Лукояновой — копию `small_`.

Логотипы АРППС, АПДП, «Фрейма» и «Души мамы» взяты из прежних загрузок (`apdp_…`, `arpps_…`, `frame_…`, `mom_…`):
они совпадают с файлами в `img/partners/` байт в байт.

## Как проверить

Открыть `glavnaya/tilda/preview.html` через локальный сервер превью: блоки стоят в обёртках, как их рисует
Тильда, ссылки перекрашены правилом `a { color: inherit !important }`, как в custom.css сайта.
Загрузка в Тильду и публикация — только по согласию Дарьи (`docs/tilda-mcp-upload.md`).
