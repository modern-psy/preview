# Блок «Цена обучения»: живые варианты

Один промо-блок цены, который сам выбирает раскладку по данным CMS. На
странице шесть курсов из Public API, каждый показывает свой режим.

## Как выбирается раскладка

`pricing-promo-render.js` (одна функция для сборки и браузера) смотрит
ответ `/api/public/course/:slug`:

| Данные курса | Режим | Что справа |
| --- | --- | --- |
| открытых потоков нет, есть «Лист ожидания» | `waitlist` | заголовок «Запишитесь в лист ожидания», без дат и потоков, строка «Забронировать место» с ценой брони |
| один поток без тарифов | `single` | одна цена на подсвеченном фоне |
| два потока без тарифов | `streams` | строки потоков без табов |
| тарифы (любое число потоков) | `plans` | строки тарифов; табы потоков при двух и более потоках; рекомендуемый = самый дорогой, с фоном |
| три и более потока без тарифов | `tabs-single` | табы, одна цена на выбранный поток |

Открытые потоки (статусы «Идет набор», «Последний шанс», «Старт в любое
время») отменяют лист ожидания. Внутри ячейки цены правила из
`docs/tilda-pricing-block.md`: крупно цена продажи, зачёркнутая только при
акции, строка рассрочки «или … ₽/мес в рассрочку (N мес.)», одно ближайшее
повышение «Цена с {дата} — {цена}». Описание тарифа берётся из поля
`description` тарифа в CMS (добавлено 17.09.2026, отдаётся API).

Слева всегда: заголовок над всем блоком, метка даты старта (кроме режимов
`waitlist` и `streams`, где даты стоят в строках), название курса и описание
для каталога из CMS.

## Файлы

Компонент общий и живёт в `apps/preview/web-academy/shared/academy/`:
контракт `pricing-promo.md`, `pricing-promo-render.js` (`PricingPromo.fromApi`,
`PricingPromo.render`, Node и браузер), `pricing-promo.css`, `pricing-promo.js`
(запрос к API и перерисовка), `pricing-promo-tilda.mjs` (сборка T123), табы
от `pricing.js`. Эта папка только потребитель:

- `theme.css`: тема страницы и подписи к вариантам.
- `data/<slug>.json`: снимки ответов API, из них при сборке строится запаска.

## Сборка

```bash
node apps/preview/pricing-variants/build.mjs
```

`--refresh` перекачивает снимки из API. Список курсов витрины в `build.mjs`.
В runtime страница ни на что вне папки не ссылается, кроме Public API.

Блок для Тильды на один курс (файл `apps/tilda/pricing-block/<slug>.html`
и два превью):

```bash
node apps/preview/pricing-variants/build-tilda.mjs <slug>
```
