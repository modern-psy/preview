# Шрифт общих стилей

`wix-madefor-text-academy.woff2` — Wix Madefor Text, урезанный для сайта Академии (29 КБ).
`wix-madefor-text-academy.woff` — тот же шрифт в формате WOFF (35 КБ) — для поля Тильды,
которое не принимает WOFF2. Внутри одинаковые знаки и насыщенности 400–800.
Собран 24.10.2026 из `WixMadeforText[wght].ttf` версии 3.100
(github.com/google/fonts, ofl/wixmadefortext; SHA-256 `7660fbcd…6fa4e1`).

- Лицензия SIL Open Font License 1.1, зарезервированных имён нет — урезать и хранить у себя можно.
  Текст лицензии и авторство сохранены внутри файла.
- Насыщенность 400–800 целиком, одним файлом. Тоньше 400 у шрифта нет.
- Знаки: латиница и Latin-1, кириллица U+0400–045F, комбинируемые ударение, бреве
  и диерезис (й и ё, набранные двумя знаками), шпации, тире, кавычки, многоточие,
  ₽, №, −, →, ▼. Набор собран по текстам всех 342 страниц карты сайта.
- В исходном шрифте нет узкого неразрывного пробела U+202F (разряды: «45 000 ₽»).
  Ему назначен глиф тонкой шпации U+2009 — переносы по нему по-прежнему запрещены.
- Цифр одинаковой ширины (tnum) и других вариантов цифр в шрифте нет:
  `font-variant-numeric: tabular-nums` на нём ничего не меняет.
- Эмодзи и редкие знаки (≈, ●, ♥) берутся из системного шрифта.

Пересобрать: fontTools (`pip install fonttools brotli`), затем

```sh
pyftsubset WixMadeforText-with-202f.ttf \
  --unicodes=0020-007E,00A0-00FF,0300-0301,0306,0308,0400-045F,2009,2010-2027,202F,20BD,2116,2192,2212,25BC \
  --layout-features='*' --flavor=woff2 --name-IDs=0,1,2,3,4,5,6,13,14 \
  --output-file=wix-madefor-text-academy.woff2
```

где `WixMadeforText-with-202f.ttf` — исходник с добавленным в cmap U+202F → `uni2009`.
После пересборки пересчитать метрики запасного шрифта в `v1.css` (раздел 1).
