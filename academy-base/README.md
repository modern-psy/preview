# Общие стили лендингов Академии

Базовые стили, одинаковые на всех новых лендингах: шрифт, цвета, поля
страницы, отступы секций и карточек, роли текста, кнопка и плашка.
На сайте они лежат один раз в custom.css Тильды, поэтому в пакеты T123
новых лендингов их больше не копируем.

Секции целиком (первый экран, форма, цены, FAQ, преподаватели…) сюда
не входят: их стили остаются в пакете страницы.

## Файлы

| Файл | Что это |
|---|---|
| `v1.css` | Исходник версии 1. Править только здесь. |
| `fonts/` | Шрифт Wix Madefor Text, 29 КБ, насыщенность 400–800. Как собран — `fonts/README.md`. |
| `test/index.html` | Проверка: v1 вместе с настоящим custom.css сайта и блок «старого лендинга». |
| `../../tilda/site-styles/custom-css-block.css` | Готовая вставка для Тильды. Собирается скриптом, руками не править. |

## Как подключить к новому лендингу

На каждую обёртку страницы ставится метка версии. В Тильде у каждого блока
T123 своя обёртка, поэтому метка нужна в каждом блоке.

```html
<div class="main-wrapper academy-page kpt-page" data-academy="1">
  <section class="section-spacing_component">…</section>
</div>
```

На превью дополнительно подключить файл в `<head>`:

```html
<link rel="stylesheet" href="/academy-base/v1.css">
```

В пакет T123 стили v1 **не** копировать: в Тильде они уже есть в custom.css.

Нельзя:

- подключать на новую страницу `components.css`, `section-heading.css`,
  `body-text.css`, `button.css` из web-academy — они перебьют v1;
- переопределять в стилях страницы токен `--hero-heading-size`
  и кегли ролей текста. Раскладку, ширины и фон секций страница задаёт сама.

Ещё в v1:

- токены цветов, шрифта, ширин и отступов web-academy;
- каркас `main-wrapper` → `padding-global` → `container-xlarge` (1520 px), поля страницы от 16 px;
- отступы секций `section-spacing_component` и карточек (`--card-padding` 16 px на всех ширинах);
- отступ при переходе по якорю: 50 px на телефоне, 100 px от 768 px;
- для iPhone: текст не раздувается при повороте, поля форм до 767 px не мельче 16 px

- цвет текста кнопок-ссылок с `!important`: custom.css сайта красит все ссылки
  правилом `a { color: inherit !important }`.

Решения по кеглям — от 24.10.2026, сверка шкал — `apps/preview/typography-check/`.

## Как устроены версии

1. Исправление, которое не меняет вид (сбой на какой-то ширине, опечатка) — прямо в `v1.css`.
   Меняется на всех страницах с `data-academy="1"`.
2. Правка, которая меняет вид, — в новом файле `v2.css` со своей меткой `data-academy="2"`.
   Новые лендинги ставят метку 2, старые переводятся по одному после проверки.
3. Одновременно живут не больше двух версий. Когда на старой не осталось страниц,
   её убирают из списка `versions` в сборщике.

Сборщик проверяет, что каждое правило начинается с метки версии, и не соберёт
вставку, если какое-то правило может задеть старые лендинги.

## Как обновить в Тильде

```sh
node scripts/build-academy-base.mjs
```

Затем в Тильде: Настройки сайта → CSS-стили (файл custom.css). Вставить
`apps/tilda/site-styles/custom-css-block.css` в **конец** файла. При обновлении
заменить всё между строками «общие стили лендингов · начало» и «· конец».
Стили шапки сайта выше этих строк не трогать.
