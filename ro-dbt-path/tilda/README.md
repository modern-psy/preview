# Обучение RO DBT в России: блоки T123 для Тильды

Страница: https://modern-psy.ru/ro-dbt-path (Тильда, страница `125901726`).
Блоки собирает `build-tilda.mjs` из `index.html`, `page.css`, `page.js` и копий формы заявки.
Файлы `NN-*.html`, `preview.html` и `manifest.json` руками не править: при следующей сборке они перезапишутся.
Правим исходники и пересобираем из `apps/preview`:

```sh
node ro-dbt-path/build-tilda.mjs
```

`preview.html` — все блоки в обёртках, как их рисует Тильда, вместе с правилом ссылок из custom.css сайта.
Открывать через локальный сервер (общие стили v1 подключены по относительной ссылке). Картинка одна — фото
Томаса Линча со static.tildacdn.com. Высоты блоков в `preview.html` совпадают с превью на 375, 768 и 1440 px
(проверено 17.11.2026).

## Общие стили v1

Шрифт Wix Madefor, H1, кнопки и роли текста приходят из custom.css сайта (вставка «общие стили лендингов»).
В пакете их нет. Каждый блок обёрнут в `main-wrapper academy-page ro-dbt-path-page` с меткой `data-academy="1"`:
без неё блок останется на старой типографике.

   из `apps/preview/web-academy/`, плюс Safari глазами.
