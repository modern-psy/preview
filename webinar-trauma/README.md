# Клиент пришёл с последствиями травмы. С чего начать работу? (вебинар 17 ноября, 18:00 МСК)

Бесплатный вебинар для психологов: как различать острую стрессовую реакцию, ПТСР и кПТСР и с чего начинать работу.
Ведущий Дмитрий Ершов, 60 минут, онлайн.

Собран 07.11.2026 по образцу /webinar-rodbt (последний бесплатный вебинар): те же общие стили лендингов v1,
тот же первый экран по эталону В3 «Описание в плашке», тот же модуль записи BotHelp + запасная форма.
`index.html`, `page.css`, `page.js` правятся напрямую, сборки нет.
Превью (после пуша): https://modern-psy-preview-5a99.twc1.net/webinar-trauma/

## Блоки сверху вниз (как в ТЗ)

1. Первый экран: вопрос-заголовок, три состояния строкой ниже, плашка «Получите схему…» с тремя вариантами
   начала работы (стабилизация, поддержка в первые дни, проработка), кнопка «Зарегистрироваться», под ней дата,
   время и «Онлайн и бесплатно, 60 минут».
2. Боль: «Клиент пришёл с последствиями тяжёлого события», четыре мысли психолога облачками, итоговая фраза
   «От того, как вы распознали состояние, зависит первая задача».
3. «Разбор трёх случаев»: тёмная плашка, три карточки с маршрутом «Что видим → Что уточняем → Первая задача».
   Первая задача взята из итоговой фразы блока боли (🟢 сверить со спикером).
4. «Что вы получите»: сиреневая плашка, три карточки с картинками-схемами (у третьей схема собирается по шагам).
5. «Кому подойдёт вебинар»: четыре карточки друг под другом, в каждой заголовок и короткое пояснение, фото справа.
6. «Что будет на вебинаре»: три случая подробно, тексты из ТЗ.
7. «Ведущий вебинара»: Дмитрий Ершов, описание и фото с лендинга «Терапия травмы: ПТСР и кПТСР» (/trauma-therapy).
8. Доказательный блок: «Витрина Академии» (один в один с /webinar-rodbt) и «98 % студентов» с оценками
   ВКонтакте 4.9, Сравни 4.82, Отзовик 4.9 (один в один с «Психиатрии для психологов», обёртка `.acad-ratings`).
9. Запись: условия, два шага, карточка с кнопками BotHelp и запасной формой (Telegram первым).
10. FAQ: четыре вопроса только по фактам ТЗ, тексты продублированы в микроразметке FAQPage.

## 🟡 Ждём

- **виджет BotHelp**: номер вписать в `data-bh-widget-id` (блок записи), вернуть загрузчик
  `widget-button.js` в `<head>` (сейчас закомментирован, поэтому на превью сразу видна запасная форма);
- **имя формы Тильды**: стоит условное `webinar-trauma`;
- **адрес страницы на modern-psy.ru**: canonical и микроразметка указывают на /webinar-trauma условно;
- **фото первого экрана**: временно с /trauma-therapy (супервизор показывает схему на листе);
- **фото «Кому подойдёт»**: временное, как на /webinar-rodbt;
- **запись эфира**: будет ли? Если да, вернуть третий шаг записи и вопрос в FAQ;
- og:image не задан.
