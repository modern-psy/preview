# Клиент пришёл с последствиями травмы: блоки T123 для Тильды

Бесплатный вебинар Дмитрия Ершова, 17 ноября 2026, 18:00 МСК. Форма Тильды: `webinar-trauma` (🟡 имя условное).
Адрес страницы: https://modern-psy.ru/webinar-ptsd (canonical и микроразметка).

Блоки собирает `build-tilda.mjs` из `index.html`, `page.css` и `page.js`.
Файлы `NN-*.html`, `preview.html` и `manifest.json` руками не править: при следующей сборке они перезапишутся.
Правим исходники и пересобираем из `apps/preview`:

```sh
node webinar-trauma/build-tilda.mjs
```

`preview.html` — все блоки в обёртках, как их рисует Тильда, вместе с правилом ссылок из custom.css сайта.
Открывать через локальный сервер (общие стили v1 подключены по относительной ссылке). Все картинки с CDN:
фото первого экрана на S3 (`webinar_trauma_client_64502f830b.webp`), остальные на static.tildacdn.com.
Высоты всех секций в `preview.html` совпадают с исходной страницей на 375, 768 и 1440 px.

## Общие стили v1

Шрифт Wix Madefor, H1, кнопки и роли текста приходят из custom.css сайта (вставка «общие стили лендингов»).
В пакете их нет. У обёртки каждой секции метка `data-academy="1"`: без неё блок останется на старой типографике.

## Форма Тильды `webinar-trauma`

Через неё уходят все заявки в amoCRM. На странице её не видно: скрипт прячет блок и отправляет его сам.

- Поля: `Name`, `Phone`. Скрытые поля скрипт добавит сам, если их нет: `messenger`, `messenger_contact`,
  `personal_data_consent`, `form_source`, `ym_client_id`, `utm_source`, `utm_medium`, `utm_campaign`,
  `utm_content`, `utm_term`.
- Приёмники: amoCRM, Telegram, Tilda CRM, как у форм других вебинаров.
- В `form_source` приходит «Заявка с лендинга «Клиент пришёл с последствиями травмы. С чего начать работу?»
  (вебинар 17.11)» и пометка: «запись через бота BotHelp» или «запасная форма: … ссылку на эфир отправить вручную».

## BotHelp

Виджет 37, customer 278875 (файл «ТРАВМА» от Дарьи, 10.11.2026). Загрузчик `widget-button.js` стоит в блоке `13-scripts`
сразу после скрипта страницы. Если BotHelp не загрузится за 10 секунд, вместо кнопок появится запасная форма
(имя, телефон, Telegram или MAX); проверить её можно, добавив к адресу `?signup=form`.
