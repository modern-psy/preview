# Блоки T123 — Терапия травмы

Каждый пронумерованный HTML-файл целиком вставляется в отдельный T123.
Порядок сверху вниз — по номеру файла. У T123 установите нулевые верхний и нижний отступы: интервалы уже находятся в CSS.
Старый монолитный блок заменяется этими блоками, а не остаётся рядом с ними.

| Файл | Содержимое |
| --- | --- |
| `00-styles-base.html` | Общие стили 1/2 |
| `01-styles-page.html` | Общие стили 2/2 |
| `02-hero.html` | Первый экран и особенности программы |
| `03-audience.html` | Кому подойдёт курс |
| `04-challenges.html` | Когда отдельных техник недостаточно |
| `05-decisions.html` | До и после курса |
| `06-outcomes.html` | Результаты обучения |
| `07-program.html` | Программа курса |
| `08-teachers.html` | Преподаватели |
| `09-education.html` | Удостоверение |
| `10-academy-showcase.html` | Об Академии |
| `11-pricing.html` | Стоимость курса |
| `12-lead-form.html` | Форма заявки |
| `13-payment-options.html` | Условия оплаты |
| `14-faq.html` | Частые вопросы |
| `15-scripts.html` | Общие скрипты |

Первые два блока содержат общие стили и подключения шрифтов. Они нужны один раз на странице; CSS разделён на две части, чтобы каждый файл был меньше 65 000 символов. Блок 15 содержит библиотеки и всю логику, его ставим последним, после секций и нативной формы Tilda. Не подключайте дополнительно прежний комплект CSS/JS этого лендинга.

Каждая секция имеет закрытую обёртку `academy-page trauma-page`: не удаляйте её, `data-trauma-block`, ID и служебные data-атрибуты. Разметка не пересекает границы T123. Скрипты работают со всеми секциями и ждут готовности DOM.

## Что остаётся в Tilda

- Штатные шапка и подвал, если они нужны на странице.
- Нативная форма с `tildaspec-formname=trauma-therapy`, прежними полями и настроенными получателями. HTML-блок формы сам по себе не отправляет заявки без этой формы.
- Popup `#form-download` для скачивания программы.
- SEO и настройки HEAD существующей страницы. Этот пакет не заменяет настройки страницы.

Контракт и mapping нативной формы сохранены в исходном JS. После вставки проверяйте на опубликованной странице работу popup, нативной формы и доставки заявки: локальное превью не содержит Tilda runtime и получателей.

## Проверка и дальнейшие правки

`preview.html` — локальная сборка всех блоков с обёртками, имитирующими T123. Её не вставляем в Tilda; `manifest.json` тоже служебный.

Контент правим в `../index.html`, стили — в `../style.css`, логику — в `../script.js`. Затем из `apps/preview` запускаем:

```sh
python3 trauma-ptsd/build-tilda.py
```

Файлы этого каталога генерируются: ручные правки HTML затрутся при пересборке. Русские комментарии в начале каждого файла указывают назначение блока.

Проверено локально: сохранение секций и всех ID, отсутствие повторных ID, размер каждого T123, совпадение геометрии с исходником на 1440 px, FAQ, слайдер, переключение MAX/Telegram и якорь регистрации. Доставка заявок в CRM не проверялась.
