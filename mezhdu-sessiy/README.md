# «Между сессий» · /mezhdu-sessiy

Проект на дизайн-системе «Между сессий UI» (Figma, файл KhGvYQCRflBC6AXKskPjiR).
Папка самодостаточная, как /sport-psy-start: свои стили, иконки, картинки.

## Файлы
- `tokens.css` — переменные из экспорта Figma (папка `tokens/`): бренд-лайм,
  нейтраль, статусные цвета, семантика текста/фона/рамок, тени, фокус-кольцо,
  шрифт, радиусы, отступы. Декоративные градиенты и токены дашборд-компонентов
  не переносились.
- `ui-kit.css` — компоненты форм по макетам: кнопки (brand + destructive,
  5 размеров, icon-only, loading), крестик модалки, утилити-кнопки, лоадеры,
  чекбоксы, радио, поля ввода (sm/md/lg, ошибка, disabled, префикс, дропдаун,
  пароль), textarea.
- `ui-kit.html` — живая витрина всех компонентов. Открывать через
  `preview`-сервер: http://localhost:4174/mezhdu-sessiy/ui-kit.html
- `index.html` + `page.css` + `page.js` — лендинг по макету Figma
  (xetOFKYyczYKIOjWZXLy7A): шапка с бургером, первый экран и трудности,
  мостик, что вас ждёт внутри клуба, аудитория, неделя в клубе,
  как попасть, FAQ, подвал. Сетка и адаптив с /sport-psy-start, контент 1280px.

  от менеджера 22.10.2026, шесть пунктов):
  фон из картинок `bg-lime-numerals.webp` и `bg-burst.webp`, иллюстрации

## Перенос в Тильду
Пакет `apps/tilda/mezhdu-sessiy` собран 09.10.2026 и устарел: в нём старый
первый экран, галерея и блок подписки. Перед пересборкой залить на S3
все картинки, лежащие рядом с index.html (первый экран: `club-circle.webp`,
`portrait-wavy.webp`, `portrait-bob.webp`; подписка: `bg-lime-numerals.webp`,
`bg-burst.webp`, `inc-library.webp`, `inc-meet.webp`, `inc-cases.webp`,
`inc-faculty.webp`, `inc-community.webp`, `inc-supervision.webp`;
«Кому будет полезно»: `aud-beginner.webp`, `aud-practice.webp`, `aud-student.webp`;
ведущие: `expert-gusachenko.webp`, `expert-kochermina.webp`) и вписать ссылки в `localImages`
страницы в `scripts/build-tilda.mjs` — без них сборка остановится
со списком файлов.
