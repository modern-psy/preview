# «Между сессий» · /mezhdu-sessiy

Проект на дизайн-системе «Между сессий UI» (Figma, файл KhGvYQCRflBC6AXKskPjiR).
Папка самодостаточная, как /sport-psy-start: свои стили, иконки, картинки.

## Файлы
- `tokens.css` — переменные из экспорта Figma (папка `tokens/`): бренд-лайм,
  нейтраль, статусные цвета, семантика текста/фона/рамок, тени, фокус-кольцо,
  шрифт, радиусы, отступы. Декоративные градиенты и токены дашборд-компонентов
  не переносились.
- `ui-kit.css` — компоненты форм по макетам: кнопки (brand + destructive,
  5 размеров, icon-only, loading), крестик модалки, утилити-кнопки, лоадеры,
  чекбоксы, радио, поля ввода (sm/md/lg, ошибка, disabled, префикс, дропдаун,
  пароль), textarea.
- `ui-kit.html` — живая витрина всех компонентов. Открывать через
  `preview`-сервер: http://localhost:4174/mezhdu-sessiy/ui-kit.html
- `index.html` + `page.css` + `page.js` — лендинг по макету Figma
  (xetOFKYyczYKIOjWZXLy7A): шапка с бургером, hero, бесконечная галерея,
  трудности, подписка, аудитория, неделя в клубе, как попасть, FAQ, подвал.
  Сетка и адаптив с /sport-psy-start, контент 1280px.
- `icons/` — SVG из Figma, stroke заменён на currentColor, красятся через
  CSS-маску.
- картинки лежат на s3.twcstorage.ru/asp-media, в репозитории их нет.
- `tokens/` — исходный экспорт из Figma, не править руками.
