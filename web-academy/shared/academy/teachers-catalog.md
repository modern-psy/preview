# Каталог преподавателей

`teachers-catalog.json` — общий каталог известных преподавателей и спикеров
Academy. Карточки отрисовываются готовым [teacher-card](teacher-card.md),
секции — готовым [Teachers](teachers.md). Не создавать отдельный компонент
на каждого человека: личные данные являются конфигурацией общей карточки.

Каждый профиль содержит `record` в формате teacher-card, `sources` и `variants`.
Локальные фотографии старых источников сохраняются в `sourcePhoto`;
если для варианта нет автономной CDN-ссылки, его `photo` равен null.
Использовать подтверждённое фото основной записи или отдельно подготовить исходник.
Варианты сохраняют контекстные описания и фотографии прежних курсов, включая
записи из Git, которые уже удалены из текущего состава. Включение в каталог
не означает участия человека в другом курсе. При новом использовании выбирать
описание, соответствующее подтверждённому составу и контексту курса.

`selectTeachers(ids, {overrides})` из `teachers-catalog.mjs` выбирает записи
в заданном порядке, проверяет ID и поддерживает явные course-owned overrides.
`renderTeachersData(records, configId)` создаёт безопасный JSON script-модуль;
`parseTeachersData(html, configId)` читает его для статической сборки.
JSON-модуль каждого лендинга — самостоятельный редактируемый источник для
Tilda. Обновление общего каталога не перезаписывает существующие составы.

Новый курс: выбрать профили → проверить состав/описания → один раз сохранить
`teachers/data.html` → использовать его в shared renderer и runtime.
После правок состава пересобирать статическую разметку и Tilda-комплект.
На странице Tilda модуль вставляется отдельно перед runtime преподавателей.

`photo`, `width`, `height` описывают исходник; `crop` — необязательная настройка
обрезки. Не подставлять чужое фото. Для Сергея Падве используется предоставленный пользователем портрет
1680×1866; URL и размеры записаны в основной записи каталога.

Первичная инвентаризация включает текущие карточки и ведущих всех лендингов
репозитория и сохранённые версии списка «Психолог-консультант» из Git.
Дубликаты объединены по имени; прежние описания и происхождение сохранены.
Для добавления новых записей использовать тот же контракт и сохранять источник.
