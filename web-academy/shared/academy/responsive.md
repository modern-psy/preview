# Общий адаптив Academy

Обязательная основа компонентов текущего и следующих лендингов. Источник
диапазонов — [responsive.json](responsive.json); решение пользователя от 15.09.2026
заменяет прежнюю границу планшета во всех общих компонентах.

| Адаптив | Ширина viewport | CSS mobile-first |
| --- | --- | --- |
| Вертикальный мобильный | до 520px включительно | базовые стили |
| Горизонтальный мобильный | 521–767px | `min-width: 32.5625rem` |
| Планшет | 768–1024px включительно | `min-width: 48rem` |
| Desktop | от 1025px | `min-width: 64.0625rem` |

Для ограниченного сверху планшетного правила использовать `max-width: 64rem`.
CSS и JavaScript `matchMedia` должны переключаться на одной границе. Значения
rem рассчитаны от стандартных 16px. Общий CSS подключается из библиотеки;
лендинг не создаёт свои копии диапазонов. Дополнительная граница внешних
колонок 1200px не меняет названия адаптивов.

Старые ширины фреймов Figma и опорные точки плавных `clamp()` — измерения,
а не границы адаптивов. Не изменять IDs, размеры ассетов и эти измерения
механической заменой чисел. Исторические отчёты остаются снимками прошлой версии.

## Использование в сборщике

Использовать обычные CSS media queries; дополнительного runtime нет.
[responsive.mjs](responsive.mjs) предоставляет JSON-контракт, `desktopMedia`
и проверку исходников для локального Node-сборщика:

```js
import {assertResponsiveContract} from '../../shared/academy/responsive.mjs';
assertResponsiveContract(styles, 'CSS');
assertResponsiveContract(runtimeJs, 'JavaScript');
```

Проверять собранный Tilda-пакет, а не старый preview. Контрольные ширины
перечислены в JSON: в том числе 767/768, 1024/1025 и прежние 991/992px,
на которых теперь не должно быть переключения планшет/desktop.
Проверять типографику, сетки, слайдеры, focus/hover, клавиатуру, no-JS,
reduced motion и переполнение. JSON и проверка нужны только при разработке;
в Tilda передаётся самодостаточный CSS/JS.

## Радиусы карточек

Обычные карточки используют общий `--radius-card`: 12px до 767px, 16px от 768px.
Источник — [card-spacing.css](card-spacing.css), обязательный вместе с карточками;
контракт и исключения — [card-spacing.md](card-spacing.md).
Карточки превью лекций используют собственный токен и шкалу 24/24/28/32px
по четырём адаптивам из [trial-lectures.md](trial-lectures.md).
