# Проверка полного Hero

Применять к изменению и переиспользованию [hero.md](hero.md). Это повторяемый
чеклист, не запись о пройденных проверках.

- [ ] Прочитаны контракт Hero, данные/медиа/actions текущего курса и его исключения.
- [ ] Весь Hero с вложенными преимуществами создан через `hero-render.mjs`;
  generated-области не исправлены вручную, чужой контент не перенесён.
- [ ] Подключены общие benefits, meta-pill, card-spacing и button; тема задаёт
  только публичные токены и внешние поля. Нет локальных копий компонентного CSS.
- [ ] Проверены 375/420/520/521/600/767/768/991/1024/1025/1440/1680px,
  границы внешней сетки курса и промежуточные fluid-размеры. 991px — опора Figma,
  не граница планшета. Композиция соответствует четырём адаптивам контракта.
- [ ] При длинном тексте и 200% размере шрифта блоки растут, карточки часов,
  преимущества, диплом и кнопки не перекрывают содержимое; overflow отсутствует.
- [ ] Один H1, корректные aria-labelledby/ID; декор с пустым alt, портреты
  с осмысленным alt; intrinsic размеры верны, изображения non-draggable.
- [ ] Главное фото не lazy, имеет fetchpriority high; кадрирование соответствует
  данным. Локальные и внешние изображения доступны в актуальном preview.
- [ ] Для композиции «текст слева, объект справа» включён `subject-right`;
  на мобильных и планшете виден главный объект, а не пустая центральная часть фото.
- [ ] Кнопки используют правильные назначения и нативные a/button; Tab/focus,
  hover, pointer и preview-состояния сохранены. Hover не сдвигает элементы.
- [ ] Без JS виден весь Hero; reduced motion не скрывает контент.
- [ ] Автономный Tilda-пакет содержит CSS и медиа, сохраняет классы SVG/span,
  не зависит от shared-путей. Проверен вместе с конфликтующими стилями Tilda.
- [ ] Выполнена визуальная сверка актуальной сборки; ограничения снимков
  отражены в STATE проекта, а не выданы за успешную приёмку.
