# Межсекционный ритм и поля тёмных секций

[section-spacing.css](section-spacing.css) задаёт на `.academy-page` внешний
`--section-space`: 60px до 520px, 80px на 521–767px, 100px на 768–1024px,
150px от 1025px. Размеры записаны в rem и масштабируются с базовым шрифтом.

`section-spacing_component` добавляет этот отступ снизу; `is-after-inset`
добавляет верхний интервал следующей секции. Hero получает тот же token через `--hero-section-end`
и `--hero-section-end-desktop`. Не добавлять второй gap на родителе.

## Общий компонент тёмной секции

`section-spacing_component.is-inset` задаёт **внутренние поля сверху и снизу**
через отдельный `--section-inset-space`: **70px desktop (от 1025px), 50px tablet
(768–1024px), 40px mobile landscape (521–767px), 40px mobile portrait (до 520px)**.
Это базовая шкала тёмных секций, включая тарифы. Для
[историй изменений в практике](practice-stories.md) пользователь утвердил
отдельную шкалу; компонент задаёт её через тот же `--section-inset-space`.
Уточнение пользователя от 2026-09-15: не подставлять сюда внешний `--section-space`.
Цвет поверхности и контент задаёт потребитель; внутренние поля принадлежат Shared.
Вложенные карточки и CTA сохраняют собственные контракты внутренних полей.

Модуль opt-in; существующие лендинги без него не меняются. Подключать после
основных компонентов и убрать старое определение `--section-space` из темы.
Он входит в HEAD автономных Tilda-пакетов. Контракт пользователя от 2026-09-11.
