# Программа обучения

Цельный статичный компонент `renderProgram(data, {id})` из [program-render.mjs](program-render.mjs).
Эталон — «Психолог-консультант», четыре Figma-адаптива в его `data/design-source.json#program_responsive`.
Контент — `data/program.json`; локальный `render-program.mjs` обновляет generated область.

Состав: общий section layout, заголовок с декоративной меткой, группа подзаголовков,
упорядоченный список этапов и общая кнопка `button_component.is-accent`.
`heading`, `subtitles`, `mark`, `stages`, `listLabel` и `action` принадлежат лендингу.
`id` задаёт уникальные ID секции и H2; H3 обозначают этапы. Тексты экранируются.
Действие — нативная ссылка на существующий раздел страницы; renderer проверяет формат якоря.
Две иконки передаются из ассетов проекта; декоративные, non-draggable, с intrinsic размерами.

## Карточка этапа

`renderStageCard({badge, heading, description})` возвращает `li.card_component.is-stage`.
`stage-card_header` объединяет `stage-card_badge` и общий `content-heading_component`;
описание — `body-text_component.is-detailed`. Другие карточки не изменяются.

| Роль | До 768px | От 768px |
| --- | --- | --- |
| Шапка карточки | Вертикальная, gap 12px | В строку, gap 12px; заголовок может переноситься |
| Padding / радиус | 12px / 12px | 16px / 16px |
| Шапка → описание | 20px | 32px |
| Gap списка | 12px | 16px |
| Заголовок карточки | 20px до 520px, далее 22px / 1.1 | 24px / 1.1 |

Высота зависит от контента. На desktop не воспроизводить фиксированные высоты
Figma и оставшиеся плюсы: пользователь согласовал статичные этапы без раскрытия.
Плашка — 15px до 520px включительно, 16px от 521px; вес 500,
line-height 1.3, padding 6px 12px, радиус 8px.
Описание ограничено max-width 899px, карточка занимает всю доступную ширину.
Перевод строки в данных описания создаёт управляемый перенос от 768px; ниже
он превращается в обычный пробел.
Цвет описания и подзаголовков — общий `--color-text-secondary-large`.
Тема эталонного лендинга использует #747476 для контраста обычного текста;
более светлый #7b7b7c из Figma не переопределяет эту доступную роль.

## Композиция и адаптив

Общие заголовки используют `section-layout_component.is-responsive` и
`section-header_component.is-responsive`; интервалы между подзаголовками
принадлежат [общей группе](section-heading.md), а не локальной секции.
Метка — 50px ниже 768px и 60px выше; малая звезда масштабируется пропорционально.
Группа описаний ограничена max-width 718px. На узком мобильном заголовок допускает
перенос после «Ваш путь в»; выше 520px — перед «шаг за шагом».

Список → кнопка: 20px до 520px, 24px выше. Кнопка занимает полную ширину до 767px,
затем ограничена max-width 454px. Её высота, шрифт, padding и состояния принадлежат
[общей кнопке](button.md), актуальная геометрия Hero заменяет старые размеры Figma.
Внешний span задаёт лендинг: здесь 10/12 от 1200px, ниже — весь контейнер.

## Поведение и доставка

Собственного JavaScript, событий и lifecycle нет. Без JS и при reduced motion
весь текст виден; ссылка работает нативно. Улучшение прокрутки — общий anchor-scroll.
Focus/hover/pointer — общий button; карточки не создают Tab stops.

HEAD: `components.css`, `card-spacing.css`, `body-text.css`, `program.css`, `button.css`,
`section-spacing.css`, `section-heading.css` и тема. BODY: готовая секция.
Все локальные зависимости и SVG встраиваются сборщиком. Проверять четыре адаптива,
границы 520/521, 767/768, 1024/1025, 1199/1200, длинный текст, zoom, ссылку с клавиатуры,
две независимые секции и текущие Tilda-фрагменты.

`renderStageCard(stage, {tag: 'div'})` позволяет использовать полную карточку
внутри нумерованного шага Learning timeline; по умолчанию остаётся `li`.
