# Табы с демонстрационными интерфейсами

`renderShowcaseTabs(data, {id, renderMedia})`, `showcase-tabs.css` и
`showcase-tabs.js` → `<academy-showcase-tabs>` в Light DOM.
По прямому поручению пользователя компонент общий; первый потребитель — КПТ Оксфорд.

Данные: `heading`, optional `accent`, `descriptions[]`, `mark.main/small`,
`label`, непустой `items[]` с уникальными `id`, `title`, `description`.
`renderMedia(item)` — доверенный build-time callback потребителя, возвращающий
семантическую разметку интерфейса. Его медиа, данные, действия и анимации
не входят в механизм табов. Никакого runtime HTML/eval из внешних данных.

Shared владеет навигацией, белой панелью, тёмной поверхностью, адаптивами,
keyboard/focus и состоянием. Desktop — колонки 0.75:1, минимальная высота 600px;
до 1025px — текст над интерфейсом. На tablet минимальная высота медиа 500px,
на мобильных высоту определяет вложение. Заголовки, описания, поля и радиусы
используют общие компоненты. Шрифт табов 15/16/18/20px; цель не меньше 44px.
Табы используют [общую плашку](tab.md), перенесённую из Teachers: высота по
строке и padding без min-height; прозрачная область нажатия не меньше 44px.
Длинные подписи переносятся без горизонтального скролла.

`data-tabs-list`, `data-tabs-trigger`, `data-tabs-panel` — behavior hooks.
JS назначает tablist/tab/tabpanel, aria-controls, aria-selected и roving tabindex.
Left/Right с циклом, Home/End автоматически активируют таб; Enter/Space — native
button click. Tab переводит фокус в активную панель. Стрелки Up/Down остаются
прокруткой страницы. Видимый focus и hover без transform.
Источник состояния — активный индекс экземпляра. Событие `academy-tabs:change`
(bubbles, detail `{id,index}`) уведомляет вложенные интерфейсы о переключении.

Без JS навигация скрыта, все пять содержательных панелей показаны последовательно.
При инициализации скрываются только неактивные панели. ResizeObserver измеряет
высоту списка табов для резерва над текстом; длинные заголовки и zoom не перекрывают
контент. Все observers/listeners удаляются при disconnect, reconnect безопасен,
повторная регистрация исключена; экземпляры и вложенные табы независимы.

CSS: components, card-spacing, body-text, section-spacing, showcase-tabs,
section-heading (после CSS потребителей). JS: showcase-tabs один раз в footer/defer.
Shared renderer не требует зависимости или сборочного runtime у посетителя.

## Анимации демонстраций

Общий источник таймингов — `demo-motion.js`, загружается перед
`typewriter.js` и `demo-sequence.js`: без пустой стартовой паузы, появление/исчезновение
200ms, пауза между этапами 500ms, удержание готового результата 4000ms,
печать 25ms на символ. Контроллеры передают длительность CSS через
`--demo-motion-duration`; скорости не дублируются в проектном runtime.
Появление карточки scale 0.96→1, действия/пунктов — мягкое проявление;
появление действия scale 0.94→1. Высота резервируется полным контентом.

Запуск при видимости не менее 50% полотна, остановка и отмена таймеров при
выходе, смене таба, скрытии вкладки и disconnect. Возврат начинает цикл заново.
No-JS, отсутствие IntersectionObserver и reduced motion показывают полное
статичное содержимое. Основной текст доступен скринридеру целиком;
временные визуальные копии имеют aria-hidden и не используют live region.

### Печать: первый, второй и четвёртый табы

`<academy-typewriter>` + `typewriter.css` / `typewriter.js`.
Каждая текстовая пара: `data-typewriter-text` с полным текстом и
`data-typewriter-visual` с временной копией. `data-typewriter-speed` (20–100ms)
переопределяет общую скорость; `data-typewriter-loop` включает повтор.
Скорость печати одинакова на всех адаптивах.

Родитель `data-typewriter-viewport` задаёт область наблюдения;
`data-typewriter-card` — появляющаяся карточка;
`data-typewriter-reveal` — декоративное действие после печати.
Карточка начинает появляться сразу, затем следует пауза 500ms после её проявления,
печать, пауза 500ms и действие. После завершения проявления действия результат
держится 4000ms, карточка исчезает, и начинается следующий цикл.

Для вопроса с вариантами: `data-typewriter-staged` + `is-sequence` на элементе,
каждая строка — `data-typewriter-step`, текстовая пара — `typewriter_step-copy`.
Строки печатаются последовательно с паузами 500ms. Через 500ms после последней
`data-typewriter-choice` получает `is-selected`; после анимации выбора и паузы
500ms появляется действие. Кружок четвёртого таба делает лёгкий bounce за общий
интервал появления. Начальные eyebrow/заголовок остаются статичными.
Кружки — иллюстрация, не настоящая анкета; находятся по центру рядом с текстом.

### Появление пунктов: третий и пятый табы

`<academy-demo-sequence>` + `demo-sequence.css` / `demo-sequence.js`.
Элементы: `data-sequence-item` + `demo-sequence_item`.
`data-sequence-order` — перестановка индексов; по умолчанию DOM-порядок.
Без пустой стартовой паузы элементы появляются по очереди с общей длительностью и
паузой 500ms. Они сохраняют место в раскладке и исчезают вместе в конце цикла.

В третьем табе порядок `1,0,2`: средняя, верхняя, нижняя карточки. Появляющаяся
карточка получает небольшой scale 1.04 и тень; предыдущая возвращается к 1.
На mobile/touch акцент 1.02 и более лёгкая тень. Затем общий hold 4000ms.

В пятом табе `data-sequence-card` обозначает общую появляющуюся карточку,
`data-sequence-reveal` — действие. После карточки последовательно появляются
три пункта, затем действие. Полный результат удерживается 4000ms.
Эти hooks предназначены для иллюстраций, а не функциональных CTA посетителя.

В Tilda CSS/JS и ассеты встраивает сборщик потребителя. Проверять четыре диапазона,
длинную навигацию, несколько экземпляров, reconnect, клавиатуру, no-JS и reduced motion.
Платформа: [MDN custom elements](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements),
[ARIA Tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/).
