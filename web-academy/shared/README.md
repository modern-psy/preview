# Shared sources

Здесь хранятся только действительно общие исходники. Перед переносом лендинга в
Tilda убедитесь, что все используемые shared-зависимости встроены, опубликованы в
подходящем месте или явно описаны в README конкретного проекта.

- `academy/` — общие Client-First компоненты лендингов Академии; перед переносом
  их CSS встраивается в самодостаточный Tilda package.
