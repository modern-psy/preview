# Перенос в Tilda

Сборка: `node projects/cbt-oxford/build-tilda-bundle.mjs` из корня репозитория.
Generated-файлы не редактировать перед вставкой. По запросу пользователя BODY
собирается с читаемыми отступами и переносами; лимит проверяется уже после
форматирования. В начале каждого BODY — комментарий с номером и названием секции.

Порядок файлов всегда берётся из `manifest.json` текущей сборки:

1. HEAD (`head.html`) — настройки страницы → дополнительный HEAD.
2. Все STYLE (`styles-1.html` — `styles-4.html`) — отдельные T123 перед содержимым.
3. Все BODY (`01-body-hero.html` — `14-body-faq.html`) — по одному T123 на секцию.
4. `teachers-data.html` — отдельный T123 с редактируемым составом преподавателей.
5. Нативная форма Tilda по [FORM-TILDA.md](../FORM-TILDA.md), до скриптов.
6. Все FOOTER (`footer.html`, `footer-2.html`) — отдельные T123 после содержимого.

Числовой префикс используется только у BODY-секций и задаёт порядок их вставки:

| Файл | Секция |
| --- | --- |
| `01-body-hero.html` | Первый экран |
| `02-body-recognition.html` | Что мешает уверенно работать |
| `03-body-course-audience.html` | Кому подойдёт курс |
| `04-body-ratings.html` | Рейтинги и оценки |
| `05-body-practice-stories.html` | Как обучение меняет практику |
| `06-body-oxford-model.html` | Оксфордская модель: табы |
| `07-body-program.html` | Программа обучения |
| `08-body-teachers.html` | Преподаватели |
| `09-body-diploma.html` | Диплом |
| `10-body-trial-lectures.html` | Бесплатные занятия |
| `11-body-pricing.html` | Тарифы и потоки |
| `12-body-form.html` | Форма заявки |
| `13-body-academy.html` | Об Академии |
| `14-body-faq.html` | Ответы на вопросы |

У T123 установить нулевые внешние поля. Каждый фрагмент меньше 65 000 символов;
точные размеры и SHA-256 — в manifest. Обновлять весь комплект одной версией,
удалять устаревшие фрагменты прошлой сборки. Количество частей может меняться.

Каждый BODY содержит ровно одну целую секцию, свой корень темы
и opt-in якорной навигации. Общий runtime не перемещает записи Tilda:
существующий `.t-records` получает единственный `role=main`, если другого main
на странице нет. Локальный preview оборачивает те же части в один main.
FOOTER разделяется между целыми скриптами с сохранением зависимостей.
Splide 4.1.4 загружается до runtime преподавателей.
Экспортный `[data-cbt-part]` сбрасывает только full-page `min-height: 100vh`;
межсекционный ритм остаётся у `section-spacing_component`, поэтому отдельные
T123 не добавляют по высоте экрана к каждому промежутку.

Декоративные SVG и небольшие изображения интерфейсов встроены. Фотографии
преподавателей и другие крупные изображения используют постоянные CDN URL;
Google Fonts и закреплённые библиотеки остаются внешними зависимостями.
Локальные `shared/` или `assets/` пути в передаваемых файлах не нужны.
`preview.html` объединяет эти же фрагменты; не вставлять его одним T123.

Состав преподавателей правится в `../teachers/data.html`, затем пересобирается
статический HTML. В Tilda соответствующий модуль остаётся отдельно редактируемым;
новый состав не должен одновременно содержать старый дублирующий модуль.

Скролл-ссылки входят в BODY как `#cbt-oxford-form` и
`#cbt-oxford-program`. Tilda popup-ссылки остаются `#form`, `#program` и
`#free-oxford`, помечены `data-tilda-popup-link` и не совпадают с ID секций.
FAQ «Напишите нам» остаётся preview-действием до подтверждения назначения.
Перед production закончить интеграцию формы по её контракту, снять preview
noindex и проверить опубликованную страницу вместе с хедером Tilda.

Intl-tel-input 29.1.2 загружается перед общим runtime формы.

Перед публикацией выполнить весь
[анти-регрессионный checklist](../TILDA-REGRESSION-CHECKLIST.md). Особое условие
для формы: marker из `data/form-contract.json` должен совпадать с
`tildaspec-formname` именно в опубликованном DOM. После загрузки скрыта только
запись `.t-rec` этой формы, а сама нативная форма остаётся в DOM.
