# Текущее состояние

Лендинг из 14 секций пересобран для повторного переноса в Tilda. Раздельные
scroll-only и popup-only действия, desktop offset 100px, защита цвета accent
button, сброс `100vh` у отдельных BODY/T123 и точный marker опубликованной
нативной формы входят в текущий manifest. Источники и команды сборки —
[README.md](README.md).

## Следующие задачи и ограничения

- После замены перечисленных Tilda-фрагментов проверить scroll-only ссылки с
  фиксированным хедером и три popup-only alias на опубликованной странице.
- In-app Browser backend недоступен; desktop автономный preview проверен во
  внешнем Chrome. Мобильная визуальная сверка остаётся через воспроизводимый
  harness `tests/browser-components.html` или после публикации в Tilda.
- Подключить назначение FAQ «Напишите нам», когда пользователь его подтвердит.
  Источник: `data/faq.json`; не выдумывать адрес.
- Нативная форма опубликованной страницы имеет marker `trauma-therapy`; он
  записан в contract, и bridge скрывает только найденный `.t-rec`. Проверить
  получателей, обе ветки мессенджера, CAPTCHA,
  соответствующее событие успеха и получение заявки в CRM. Preview не отправляет
  заявки без нативной формы.
- Финальный перенос в Tilda, production SEO и проверка опубликованной страницы
  остаются впереди. Переносить весь текущий комплект по `tilda/manifest.json`.
