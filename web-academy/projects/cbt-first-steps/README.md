# Первые шаги в КПТ

Локальная реализация лендинга бесплатного мини-курса. Сейчас готовы header,
hero, блок аудитории, результаты знакомства с КПТ, устройство мини-курса,
программа из пяти уроков, ведущий, CTA с грантом, блок об Академии и футер.

Перед продолжением работы прочитать проектные правила в `AGENTS.md`, текущий
чеклист в `STATE.md` и реестр источников ассетов в `data/assets.json`.

Готовый пакет для переноса в Tilda находится в `tilda/`. Он генерируется только
из source-файлов командой `node build-tilda-bundle.mjs`; инструкция по вставке,
SEO-настройки и post-publish checklist находятся в `tilda/README.md`.

## Локальный просмотр

Из корня `web-academy`:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:4173/projects/cbt-first-steps/>.

## Компоненты

- `site-header` — статичная шапка с логотипом, промо-плашкой и CTA.
- `hero_component` — декоративное маскированное изображение и две колонки
  контента; основной текст доступен без CSS и JavaScript.
- `info-grid_component` / `info-card_component` — локальная карточная сетка.
  Вариант `is-compact` используется для кратких признаков аудитории.
- `course-format_component` — тёмная информационная карточка с семантической
  последовательностью из трёх шагов; интерактивного поведения нет.
- `course-program_component` — пять семантических карточек уроков с локальными
  WebP и точными Figma-масками. На tablet/desktop карточки наслаиваются через
  CSS sticky; `script.js` подбирает безопасную точку остановки по высоте окна.
- `course-speaker_component` — профиль Алексея Бабурина и список квалификаций,
  адаптированные из утверждённого Academy-компонента.
- `grant-cta_component` — тёмный CTA по Figma; ссылка пока ведёт к программе,
  пока production destination не утверждён.
- `academy-showcase_component` — адаптированный из ленда «Терапия травмы»
  статичный блок из четырёх карточек; тексты и композиция соответствуют Figma
  node `366:66`, включая значение «Более 4000 выпускников» и карточку
  преподавателей.
- `footer_component` — адаптированный из ленда «А что, если стать психологом»
  футер на белом фоне хедера, с его логотипом, текстовыми ссылками без
  подчёркивания, серым hover-состоянием и внутренней шириной
  `container-content`.

Все изображения подключаются через `<img>`. Hero, иллюстрации программы и
декоративные иконки имеют пустой `alt`; портрет ведущего и логотип получают
контекстные доступные имена.
Tilda-пакет переносит локальные SVG/WebP в постоянные CDN URL или data URL по
правилам `rules/engineering/tilda-svg-and-masks.md`.

## Tilda package

После изменений source пересоберите пакет и запустите проверки:

```sh
node build-tilda-bundle.mjs
node --test tests/tilda-bundle.test.mjs
```

Сгенерированные `tilda/*.html` вручную не редактируются. `head.html` и
`body.html` переносятся только парой; `schema.html` добавляется в HEAD ровно
один раз, а `footer.html` подключает проектный JavaScript в последнем T123.
