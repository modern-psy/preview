# Проверка «Психолог-консультант»

Повторяемый чеклист, а не журнал выполненных проверок. Применять затронутые
пункты к текущей сборке. Источник требований — [AGENTS.md](AGENTS.md), точные
контракты — [COMPONENTS.md](COMPONENTS.md) и [design-source.json](data/design-source.json).

## Сборка и условия проверки

- [ ] Локальный сервер запущен, Browser подключён до визуальных изменений;
  ограничения backend или снимков явно указаны.
- [ ] Обновлён `build-tilda-bundle.mjs --preview-only`; проверяется текущий
  `tilda/preview.html`, включая встроенные CSS/JS и конфликтующий цвет Tilda.
- [ ] Проверены 375, 768, 1024, 1440px и границы 520/521, 767/768, 1024/1025,
  1199/1200px; для Hero также пройден [общий чеклист](../../shared/academy/hero-checklist.md).
- [ ] Нет горизонтального overflow страницы, ошибок console/network,
  пропавших медиа; alt, intrinsic размеры и non-draggable сохранены.
- [ ] Проверены Tab, Enter/Space, стрелки, focus/hover и touch; цели минимум
  44px, кнопки не двигаются на hover, preview-CTA сохраняют pointer и focus.

## Единые роли и интервалы

- [ ] Computed размеры, веса и line-height соответствуют shared-ролям,
  утверждённые исключения из AGENTS сохранены. Старый аудит не используется как спецификация.
- [ ] Шапка → содержимое следует общей шкале [spacing.md](../../shared/academy/spacing.md),
  включая таймлайн, преподавателей, команду и FAQ. Заголовок → подзаголовки и
  промежутки между двумя подзаголовками проверены отдельно.
- [ ] CTA с описанием и без имеют одинаковый отступ до кнопки своей ширины.
- [ ] Обычные карточки используют общий радиус; превью лекций — свою шкалу.
  Открытые вопросы аудита не объявлены автоматически исправленными.

## Общая сетка и секции

- [ ] Все основные кнопки, включая submit формы, используют
  [button_component](../../shared/academy/button.md): размеры совпадают с
  текущим Hero на одной ширине viewport. Старые размеры из остальных
  Figma-секций не возвращены; секции управляют только размещением и шириной.
- [ ] Общий `button.css` встроен в слой STYLE полного пакета; длинные подписи и увеличение шрифта
  не обрезаются, disabled/busy формы и preview-состояния сохранены.
- [ ] Поля 16px до 767px, 24px на 768–1199px, 80px от 1200px.
- [ ] Общий межсекционный интервал 60/80/100/150px в четырёх диапазонах.
- [ ] Карточки Hero (преимущества и часы) и обе карточки practice-path также
  используют общий `--card-padding`; изображения не перекрывают текст,
  диплом practice-path прилегает к низу.
- [ ] Recognition и foundation используют один icon-card: иконка 40px,
  gap иконка/текст 20px ниже 1025px и 28px выше; пары текста foundation 8/12px.
  Padding обоих вариантов — общий `--card-padding`, gap карточек и до CTA —
  `--card-grid-gap`: 12px ниже 768px, 16px от 768px.
- [ ] Practice path: нет пересечения текста и изображений, созвон центрирован,
  диплом прилегает к низу; родительская высота растёт при длинном тексте.
- [ ] Три grid CTA имеют общий renderer и responsive CSS; без JS контент виден,
  touch сохраняет статичную подсветку, reduced motion не создаёт кометы,
  повторная инициализация не размножает ячейки.
- [ ] `build-ratings-bundle.mjs` создаёт независимые HEAD/section без локальных
  путей и JS; блок проверен отдельно от CSS психолога-консультанта.
- [ ] До 1200px все секции на полную ширину контейнера: отдельно проверить
  «Узнаёте себя», программу, поступление, форму, тарифы и FAQ. Полноширинный
  контейнер не означает обязательную одну колонку внутри секции.
- [ ] Сохранён порядок program → learning → trial-lectures → support-team →
  teachers → diploma → graduation.
- [ ] Таймлайн: центры кругов/молнии совпадают с центром первой строки подписи;
  длинная подпись «Эксперт» использует общую типографику и доступную ширину.
- [ ] Сетка таймлайна сохранена: до 768px подписи над карточками и круги слева,
  от 768px подписи в левой колонке. Нет центрированной portrait-композиции
  из Figma; все восемь шагов используют правильные тексты из одного JSON.
- [ ] Шрифты и внутренние интервалы обычной и Expert-карточки соответствуют
  `data/design-source.json#learning_timeline`; при 200% тексте карточки и
  подписи растут и переносятся, без горизонтального переполнения компонента.
- [ ] Линия таймлайна следует 90% высоты viewport; no-JS/reduced-motion
  показывают полную линию. Повторный init, несколько экземпляров и cleanup
  сохраняют поведение; кнопка с клавиатуры ведёт к `#pricing`.
- [ ] Команда: супервизоры первыми до 520px; две колонки на 521–767px,
  карточка с тегом третья по центру шириной в колонку; три колонки от 768px.
  Сообщество на всю ширину до 1024px, 67.5625% от 1025px. Готовый crop сохранён.
- [ ] Отдельная team-card и два экземпляра секции работают без JS и при 200% тексте;
  тег команды совпадает с Hero, включая размер SVG/span после переноса.
- [ ] Лекции: мобильная рамка 200px, поля 20/24px, карточки обрезаны справа
  и снизу, нижняя затухает в сиреневый фон; заголовки 32px, описания 18px,
  SVG play 60×60px. На планшете сохранены центрирование и высота 320px;
  от 1025px высота равна соседней карточке. Имена лекций берутся из данных.

## Академия, тарифы и поступление

- [ ] Все три секции используют общие renderer и CSS с проектными JSON;
  generated области не исправлены вручную. Проверены независимые экземпляры
  и текст 200%; содержимое не перекрывается медиа и не обрезается.
- [ ] Академия: на вертикальном мобильном все карточки, включая выпускников,
  используют заголовок 24px и описание 16px. Сетка, минимальные высоты и медиа
  следуют `academy-showcase-responsive.css`, legacy aspect-ratio не возвращён.
- [ ] Академия без необязательной карточки преподавателей не оставляет пустой ряд.
  Свечения и обрезка фото сохранены в автономной Tilda-сборке.
- [ ] Тарифы: на portrait иконки списков и огонь 16×16px, от 521px — 18×18px;
  шрифты соответствуют разным ролям из общего контракта. Мобильный gap перед
  ценой — 48px; minimum 17rem на планшете сохранён.
- [ ] Тарифы: ниже 768px популярный план первый в DOM, выше порядок из JSON.
  Первым выбран зимний поток (9 декабря), вторым идёт весенний (16 марта).
  Цены обоих потоков соответствуют `data/pricing.json`; табы, ARIA,
  клавиатура, reconnect и повторный init работают без дублирования событий.
  Без JS видны оба потока, при reduced motion смена мгновенная;
  обычные переходы используют проектные 150ms ease-in-out.
- [ ] Поступление стоит сразу после тарифов, перед грантом. На portrait документы
  в одну колонку, на landscape два рядом и диплом ниже; от 768px H2 слева.
  Сетка переносится при увеличенном тексте, диплом не перекрывает заголовок.
  Иконки документов сохраняют оболочку 40×40px и внутренний SVG 20×20px.

## Преподаватели и отзывы

- [ ] Секция и отдельная teacher-card используют shared исходники; четыре
  размерные шкалы соответствуют `data/design-source.json#teachers`.
  Все карточки остаются в слайдере на каждом экране; два экземпляра независимы.
- [ ] Все записи из `teachers/data.html` представлены в табах и карточках
  в порядке массива; непустые теги с заглавной буквы; фото либо согласованная заглушка.
- [ ] Desktop-табы по самому длинному имени с padding, вертикальный scroll
  без полосы. При составе >8: три flex-ряда ниже 768px, два на 768–1024px;
  ряды прокручиваются вместе и не образуют выровненные колонки.
- [ ] Доли карточек соответствуют [контракту](teachers/README.md#поведение-и-адаптив).
  Справа лента выходит до края viewport; в конце нет пустого хвоста.
- [ ] Клик последнего таба, стрелки, drag, горизонтальное колесо и клавиатура
  синхронизированы. Вертикальное колесо прокручивает страницу; крайние стрелки
  учитывают реальные позиции, без пустых кликов на одинаковом смещении.
- [ ] Оба слайдера используют `AcademySliderControls`; переключение реально
  проходит промежуточное положение за 400ms, а не прыгает мгновенно.
- [ ] Resize, refresh, удаление/повторное подключение и повторная инициализация
  не дублируют listeners; выбранный таб и ARIA остаются согласованными.

## FAQ и motion

- [ ] Обычный preview не подменяет системный reduced motion даже при старом
  `?motion=reduce` в адресе. Принудительный режим есть только на тестовом стенде.
- [ ] FAQ реально проходит opening/closing за 300ms; проверено промежуточное
  состояние и завершение, включая быстрый повторный клик и смену вопроса.
- [ ] В single-режиме после завершения открыт один ответ; при resize высота
  естественная, без JS работает native details, reduced motion сохраняет доступность.

## Форма и Tilda

- [ ] Пустая форма: оба status icon скрыты. Неверное поле: только error,
  сообщение и aria-invalid=true. После исправления: только success.
- [ ] Email, неполный телефон и Telegram без @ отклоняются; корректные активные
  поля включают submit. Переключение MAX/Telegram отключает скрытую ветку.
- [ ] Код страны, текст телефона, CTA, hover/focus и disabled имеют нужные
  цвета под тестовым `a,button { color:red!important }`.
- [ ] Generated SVG/span defaults не перебивают `display:none` и состояния
  компонентов; ошибка и успех никогда не показаны одновременно.
- [ ] Для bridge проверены mapping, одна передача, busy/error, чужой success
  и CAPTCHA по [общему контракту](../../shared/academy/lead-form.md).
  Локальная валидация не считается подтверждением доставки в CRM.
- [ ] Standalone teachers HEAD/section/data/FOOTER самодостаточны; данные
  редактируются отдельным T123, без дублирования секции в полном BODY.
- [ ] Программа: между подзаголовками 4/8/12/16px, до группы 20/20/24/28px;
  карточки статичны, `is-stage` и общий Body Text/кнопка сохраняют адаптив.
- [ ] Каждый HEAD/STYLE/BODY/FOOTER из manifest проходит лимит T123 и повторную сборку с одинаковыми hashes;
  порядок T123 соответствует generated README. Проверить CTA, FAQ и слайдеры
  во всех корнях, единственный main landmark и форму после последнего BODY.
- [ ] ZIP содержит текущие файлы manifest и инструкцию, hashes совпадают.
  После визуальных изменений существующий Vercel preview обновлён; опубликованный
  HTML совпадает с `exports/vercel/index.html`.
