# Преподаватели

Секция `#teachers` между командой поддержки и дипломом. Контент и порядок
задаются в **[data.html](data.html)** — отдельном HTML-модуле с JSON внутри
`<script type="application/json">`. Это источник данных по прямому поручению
пользователя; отдельной копии JSON нет.

Для изменения преподавателя редактируйте `name`, `tag`, `photo`, `description`.
Для добавления скопируйте объект и задайте уникальный `id` латиницей. Перемещайте
объекты целиком: порядок массива одновременно определяет порядок табов и карточек.
`photo: null` показывает инициалы. После получения фотографии замените `null`
на HTTPS-ссылку. `tag: ""` убирает плашку. Тексты — обычный текст, без HTML.
Все непустые теги должности записываются с заглавной буквы.
Кавычки внутри текста экранируются как `\"`; символ `<` — как `\u003c`.

Портреты используют предоставленные пользователем ссылки Tilda CDN.
У преподавателей без ссылки — заглушки; прежние фотографии Figma не используются.

Алексей Бабурин удалён из состава по поручению пользователя; не возвращать его
из старых Figma-узлов или generated-фрагментов. Ссылка на фото Сергея Падве сама
по себе не добавляет его в состав. Актуальные имена, порядок и портреты задаёт
только `data.html`, метаданные файлов — `../data/assets.json`.
При замене портрета удалите необязательный `crop` (геометрия
`[ширина%, высота%, слева%, сверху%]`), чтобы новое фото заполняло карточку
стандартным `object-fit: cover`. Обновите `width` и `height` по размерам файла.

## Фотографии без пустых краёв

При заданном `crop` изображение должно полностью перекрывать медиарамку:
`слева ≤ 0`, `сверху ≤ 0`, `ширина + слева ≥ 100`, `высота + сверху ≥ 100`.
Не растягивать файл с искажением пропорций. Если смещение открывает край фона,
исправлять его в `data.html`, сохраняя композицию портрета.
Проверять покрытие рамки на 375, 768, 1024 и 1440px,
в исходнике и автономном превью после сборки.

## Локальная сборка

Из корня репозитория:

```sh
node projects/psychologist-consultant/teachers/build-tilda.mjs
node projects/psychologist-consultant/build-tilda-bundle.mjs
```

Первая команда обновляет область `teachers:start/end` в `index.html` и собирает
изолированный комплект [tilda/](tilda/). Вторая обновляет полный комплект и превью лендинга.
Общие [teachers](../../../shared/academy/teachers.md) и
[teacher-card](../../../shared/academy/teacher-card.md) используются и при
локальной генерации, и при чтении блока данных Tilda. Заголовок и подписи —
`../data/teachers-section.json`.

## Вставка в Tilda

Для отдельной секции используйте комплект именно из **teachers/tilda/**:

1. `head.html` — в HEAD страницы (стили и шрифт).
2. `section.html` — T123 на месте секции, над дипломом.
3. **`data.html` — отдельный редактируемый T123 с преподавателями.**
4. `footer.html` — T123 после двух предыдущих блоков. Уже загруженный Splide
   переиспользуется; иначе загружается закреплённая версия 4.1.4.

После вставки можно менять состав в T123 с данными, не переписывая секцию:
при загрузке страницы она заново формирует табы и карточки из этого блока.
Фотографии загружаются по HTTPS-ссылкам из модуля данных.
Репозиторий в браузере не нужен.
Внутри секции сохранена статичная версия контента на случай отключённого JS;
чтобы обновить и её после редактирования Tilda, внесите те же изменения в
исходный `teachers/data.html`, пересоберите и замените `section.html`.

Не вставляйте секцию второй раз, если она уже входит в полный BODY лендинга.
В полном комплекте данные вынесены в `tilda/teachers-data.html`, а стили и
поведение включены в общие STYLE/FOOTER. Полный BODY разделён на несколько
T123 по целым секциям; актуальный порядок — [полная инструкция](../tilda/README.md).
Каждый файл, включая HEAD отдельной секции, проходит лимит 65 000 символов.

## Поведение и адаптив

- `academy-teachers` — общий Light DOM Custom Element, без Shadow DOM.
- Табы, стрелки, перетаскивание мышью и свайп управляют одним Splide.
- На desktop список имён имеет intrinsic/max-content ширину по самому длинному
  имени плюс padding. Высота синхронизирована с фотографией. Вертикальный scroll
  сохранён, scrollbar скрыт; fade исчезает в конце списка.
- Если преподавателей больше восьми, имена идут в трёх flex-рядах до 768px и
  в двух рядах на 768–1024px внутри одного горизонтального scroller. Более короткий
  список остаётся в один ряд. Ширины пунктов по тексту, без общих колонок.
  Порядок читается по рядам сверху вниз. Слайдер работает на всех ширинах:
  до 520px карточка занимает 85% ширины, оставляя видимым край следующей;
  на 521–767px видно примерно 1,75 карточки, на 768–1024px — две. На 1025–1199px ширина рассчитывается
  из 1.65 карточки, от 1200px — из 2.7, воспроизводя desktop-композицию Figma.
- Справа карточки выходят за контейнер до края экрана. Слева они отсечены на
  границе с табами. В конце последняя карточка останавливается у правой границы
  контейнера; пустое место после неё не появляется.
- Стрелки клавиатуры следуют ориентации списка; Home/End выбирают первый/последний
  таб, Enter/Space активируют. Одна Tab-позиция в списке, видимый focus и
  синхронные `aria-selected`/`aria-controls`/`tabpanel`.
- Без JS или CDN — полный список карточек и якорные ссылки; контролы скрыты.
- Motion использует токены страницы; reduced motion сохраняет переключение без
  анимации. Удаление элемента освобождает Splide, observers и listeners;
  повторное подключение сохраняет выбранного преподавателя. `refresh()` повторно
  читает модуль данных. Ошибка данных оставляет предыдущую статичную разметку.

API проверен по [Splide](https://splidejs.com/guides/options/),
[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements)
и [WAI carousel pattern](https://www.w3.org/WAI/ARIA/apg/patterns/carousel/).

Управление и анимация используют общий `AcademySliderControls` из секции отзывов:
стрелки, горизонтальные жесты, клавиатуру и остановку у реального конца ленты.
`--slider-duration: 400ms` задаёт перелистывание; системный reduced motion
отключает движение. Сборщик встраивает тот же исходник в отдельный Tilda-модуль.
