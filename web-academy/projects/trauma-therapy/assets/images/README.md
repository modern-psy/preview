# Изображения лендинга

В этой папке лежат локальные исходные копии изображений, переданных для лендинга.
В production-разметке используются постоянные Tilda CDN URL.

Канонический реестр со ссылками, размерами, назначением и текущим местом
использования: [`../../data/assets.json`](../../data/assets.json).

## Состав

- `trauma-therapy-hero.webp` — главное изображение Hero;
- `course-audience-students.webp` — фотография блока «Кому подойдет курс»;
  используется в переиспользуемом компоненте `media-card-list_*`;
- `trauma-therapy-after.webp` — терапевтическая сессия под стеклянными
  карточками результата в секции 4;
- `trauma-therapy-course-notes.webp` — участница делает записи; вертикальный
  исходник для media/card-компонента секции 5.
- `alexandra-romanovskaya.webp`, `daria-suchilina.webp`,
  `ulyana-avchinnikova.webp`, `yulia-glazkova.webp`,
  `natalia-minibaeva.webp`, `tatyana-orlova.webp`, `dmitriy-ershov.webp` — семь
  портретов преподавателей в порядке слайдера;
- `trauma-therapy-diploma.webp` — удостоверение в секции документа об
  образовании;
- `academy-practice.webp`, `academy-community.webp`,
  `academy-graduate-primary.webp`, `academy-graduate-small.webp`,
  `academy-graduate-medium.webp` — изображения переиспользуемого блока об
  Академии, сохранённые с его постоянных Tilda CDN URL.
