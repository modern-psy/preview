# Иконки лендинга

В этой папке лежат локальные исходные копии SVG, переданных для лендинга
«Терапия травмы: ПТСР и кПТСР». Они нужны для архива, проверки и последующей
переиспользуемости. В production-разметке Tilda используются постоянные CDN URL.

Канонический реестр со ссылками, размерами, назначением и текущим местом
использования: [`../../data/assets.json`](../../data/assets.json).

## Состав

- `clock-alert-dark.svg` — дата старта в светлой metadata pill Hero.
- `earth-white.svg` — формат «Онлайн» в акцентной metadata pill Hero.
- `clock-alert-white.svg` — примечание о ближайшем старте под CTA.
- `astroid-accent.svg` — общая акцентная иконка информационных карточек всего
  лендинга; она не принадлежит компоненту Hero.
- `box-accent.svg`, `shapes-accent.svg`, `waypoints-accent.svg`,
  `radius-accent.svg`, `ungroup-accent.svg`, `blocks-accent.svg` — декоративные
  маркеры шести карточек раздела «Когда отдельных техник уже недостаточно».
- `double-shapes-accent.svg` — переиспользуемый двойной shape 60×60 над
  заголовками секций 4 и 5.
- `percent-accent.svg` — общая декоративная иконка для карточек с условиями
  оплаты.
- `calendar-clock-white.svg` — длительность программы в левом sticky-блоке;
- `file-download-dark.svg` — ссылка на скачивание полной программы;
- `clock-muted.svg` — часы и недели в заголовках модулей;
- `slider-arrow-muted.svg`, `slider-arrow-light.svg` — неактивное и активное
  состояния стрелок преподавательского слайдера. У этих двух Figma-экспортов
  нет постоянного Tilda CDN URL, поэтому при финальном переносе они инлайнятся
  как data URL.
- `messenger-max.svg`, `messenger-telegram.svg` — исходные пользовательские SVG
  для radio-кнопок мессенджера; в рабочей разметке их path инлайнится с
  `currentColor`, чтобы выбранное и hover-состояния меняли цвет синхронно с
  текстом.
- `form-error.svg`, `form-success.svg` — состояния inline-валидации полей формы.
  До переноса в Tilda их локальные URL нужно заменить на inline SVG или data URL.
- `form-search.svg` — пользовательская иконка поиска для тёмного списка стран;
  применяется как CSS-mask, чтобы цвет оставался контрастным фону. До переноса
  в Tilda локальный URL маски нужно заменить на data URL.

## Добавление новых иконок

1. Сохранить исходный файл без перерисовки под понятным purpose-based именем.
2. Добавить в `../../data/assets.json` локальный путь, исходную Tilda CDN ссылку,
   intrinsic-размер, место использования, назначение и семантику.
3. Для декоративной иконки оставить `alt=""` и убрать её из accessibility tree.
4. Не заменять постоянную Tilda CDN ссылку временной ссылкой из Figma.
