# CTA-графика

`grid.svg` — канонический декоративный фон интерактивного CTA из секции 3. По
прямому указанию пользователя он переиспользован из лендинга «А что если стать
психологом» и побайтно совпадает с SVG, экспортированным из Figma-узла `14:770`.

`grid-tall.svg` — высокий вариант `1198×492` для панели «До курса» в секции 4.
Он побайтно совпадает с временным Figma MCP экспортом узла `21:1275`, который
был сохранён локально до истечения ссылки.

Локальная страница подключает оба файла из `index.html`. При переносе в Tilda
каждый SVG нужно встроить как data URL в `<img class="cta_grid-image">`, как это
сделано в исходном Tilda-пакете компонента. Не заменять файлы временными Figma
MCP ссылками.

Графика декоративная: контейнер скрыт от accessibility tree, а `alt` остаётся
пустым.
