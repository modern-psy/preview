# Landing projects

Создавайте каждый лендинг в отдельной папке `projects/<project-slug>/`.
Страница должна открываться через локальный статический сервер и оставаться
пригодной для переноса в Tilda без обязательного production-деплоя.

- `content-workshop/`;
- `what-if-become-a-psychologist/`;
- `anti-crisis-conference/`;
- `ast-shrek-in-psychologists-office/`;
- `cbt-first-steps/`;
- [`cbt-oxford/`](cbt-oxford/) — «КПТ Оксфорд»;
- [`psychologist-consultant/`](psychologist-consultant/) — «Психолог-консультант».
