# «Шрек в кабинете психолога»

Локальный исходник лендинга вебинара о первом знакомстве с ACT. Страница
собирается на semantic plain HTML/CSS и использует компонентную архитектуру,
12-колоночную сетку и вертикальный ритм лендинга «Терапия травмы».

## Локальный просмотр

Из корня репозитория запустите статический сервер и откройте проект:

```text
python3 -m http.server 61441 --bind 127.0.0.1
http://127.0.0.1:61441/projects/ast-shrek-in-psychologists-office/
```

## Перенос в Tilda

Соберите самодостаточные фрагменты командой:

```text
node projects/ast-shrek-in-psychologists-office/build-tilda-bundle.mjs
```

Готовые `head.html`, `body.html`, `footer.html`, `schema.html` и manifest находятся
в `tilda/`.
Перед добавлением формы обязательно прочитайте `tilda/AGENTS.md`: форма должна
остаться между ведущей и блоком Академии и занимать 10 из 12 колонок. CDN-изображения
и иконки уже используют постоянные Tilda URL.
