# Tilda transfer package

Фрагменты генерируются из source-командой:

```text
node projects/ast-shrek-in-psychologists-office/build-tilda-bundle.mjs
```

Перед работой с формой обязательно прочитайте соседний `AGENTS.md`.

## Вставка

1. Содержимое `head.html` добавьте в HTML-код страницы внутри `HEAD`.
2. Туда же добавьте `schema.html` ровно один раз.
3. Содержимое `body.html` вставьте в один T123-блок.
4. Содержимое `footer.html` вставьте в последний T123-блок после BODY.
5. Нативную форму Tilda и мост готовой формы настраивайте по проектному
   `AGENTS.md`; после изменений пересоберите пакет.

Год вебинара в видимом copy пока не указан, поэтому схема намеренно не содержит
`startDate`. Добавляйте точную дату только после подтверждения года.

Фрагменты самодостаточны и не зависят от repository-local `shared/` файлов.
