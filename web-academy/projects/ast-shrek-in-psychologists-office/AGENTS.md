# «Шрек в кабинете психолога» — правила проекта

- Визуальным источником являются указанные пользователем Figma-узлы текущего
  файла; постоянные медиа берутся только из явно предоставленных Tilda URL.
- Компонентная архитектура, Client-First классы, семантика, 12-колоночная сетка,
  отступ от хедера до hero и вертикальный ритм наследуют контракты лендинга
  `projects/trauma-therapy/`.
- Из других лендингов переносить только явно названные пользователем компоненты.
- Исходник остается semantic plain HTML/CSS/JavaScript без framework/runtime.
- Итоговая Tilda-разметка обязана быть самодостаточной и не зависеть от
  repository-local `shared/` файлов.
