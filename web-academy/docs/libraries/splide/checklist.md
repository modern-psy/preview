# Splide delivery checklist

## Structure

- [ ] Один Splide root имеет один экземпляр и уникальное accessible name.
- [ ] Обязательные `splide__track`, `splide__list`, `splide__slide` сохранены.
- [ ] Client-First классы отделяют проектное оформление от API-классов.
- [ ] Все изображения имеют корректный `alt`, размеры и `draggable="false"`.

## Interaction and accessibility

- [ ] Стрелки и controls доступны клавиатурой и имеют touch-area 44×44 px.
- [ ] Есть видимый `:focus-visible`.
- [ ] Скрытые слайды не создают ошибочный tab order.
- [ ] Autoplay имеет play/pause и останавливается на hover/focus.
- [ ] Проверен `prefers-reduced-motion: reduce`.
- [ ] При обычном motion проверено реальное промежуточное смещение и завершение
  перехода; одна конечная позиция не доказывает наличие анимации.
- [ ] Для Academy переиспользован `AcademySliderControls`; вертикальное колесо
  не переключает ленту, горизонтальные жесты, стрелки и клавиатура согласованы.
- [ ] Последний таб и стрелки останавливаются у реального конца: нет пустого
  хвоста и повторных кликов между индексами с одинаковым смещением.
- [ ] Russian `i18n` labels понятны screen reader.

## Responsive and lifecycle

- [ ] Проверены 375, 768, 1024 и 1440 px.
- [ ] Проверены обе стороны изменённых breakpoint и длинный список табов;
  край отсечения ленты соответствует проектному контракту container/viewport.
- [ ] Нет обрезания box-shadow, focus outline и соседних слайдов.
- [ ] Resize не оставляет неверные ширины или позиции.
- [ ] Инициализация не дублируется в Tilda preview/editor.
- [ ] Повторная инициализация предварительно вызывает `destroy(true)`.
- [ ] В console нет ошибок, а без JavaScript контент остаётся доступным.
