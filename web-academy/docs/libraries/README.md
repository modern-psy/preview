# Frontend knowledge and libraries

Локальная база только для тех frontend-соглашений и библиотек, которые реально
используются текущими лендингами Web Academy.

Документы не заменяют официальную документацию. Они фиксируют выбранный для
репозитория способ использования библиотек с учётом plain HTML/CSS/JavaScript,
Client-First, доступности и последующего переноса в Tilda.

## Разделы

- [Splide](splide/README.md) — карусели и слайдеры.
- [Motion](motion/README.md) — основной инструмент JavaScript-анимации.
- [Client-First](client-first/README.md) — структура и именование HTML/CSS.
- [Web Components](../../rules/engineering/components.md) — уровни переиспользования,
  progressive enhancement, lifecycle и публичные контракты компонентов.

## Общие правила

- Подключать только библиотеку и плагины, которые действительно нужны странице.
- В итоговом Tilda-коде использовать CDN с точной версией, без `@latest`.
- Проверять актуальную версию и release notes перед первым подключением к проекту.
- Инициализацию делать идемпотентной: повторный запуск не создаёт второй экземпляр,
  обработчики или анимацию поверх первого.
- Всегда предусматривать очистку экземпляров и слушателей.
- Essential content не должен зависеть от успешной загрузки JavaScript.
- Соблюдать `prefers-reduced-motion: reduce`.
- После подключения проверять страницу на 375, 768, 1024 и 1440 px, клавиатурой
  и в Tilda preview/editor.

Не хранить локальные пересказы неиспользуемых библиотек: при новом подключении
проверять актуальную официальную документацию и фиксировать только принятое
репозиторное решение.
