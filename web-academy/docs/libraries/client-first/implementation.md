# Client-First implementation rules

## Naming workflow

Перед созданием класса определить:

1. Какую ответственность он несёт?
2. Это reusable utility, global component или project-owned element?
3. С какими классами его будут искать и редактировать?
4. Нужен ли отдельный wrapper для layout, scope, spacing или semantics?

Имя описывает назначение и отношение, а не внешний вид:

```text
conference_schedule_item     good
conference_schedule_time     good
left-purple-box              bad
item-new                     bad
```

Не смешивать Client-First с BEM `__`/`--`, autogenerated hashes или shorthand.

## Typography

- Начинать с semantic `body`, `h1`–`h6`, `p`, `a`, `ul`, `ol`.
- Visual heading class добавлять только при расхождении semantic level и размера.
- Повторяемые вариации оформлять как `text-size-*`, `text-weight-*`,
  `text-color-*`; уникальные — component-owned class.
- Не использовать `<br>` и block spans для обычного переноса текста.
- Управлять длиной строки через fluid `width`/`max-width` и font metrics.

## Spacing and layout

- Для повторяющихся siblings предпочитать `gap`.
- `padding-global` отвечает только за horizontal gutters.
- `padding-section-*` отвечает только за paired vertical section padding.
- One-off asymmetric spacing принадлежит конкретному component/wrapper.
- Не использовать пустые spacer elements.
- Не фиксировать ширину/высоту content blocks без функциональной причины.

## Variables and units

CSS custom properties называются по смыслу:

```css
:root {
  --color-text-primary: #18181a;
  --color-surface-primary: #ffffff;
  --space-section-large: 6rem;
  --radius-card: 1.5rem;
  --container-large: 75rem;
}
```

- `rem` — основной unit для type, spacing, size и radius.
- `1px` — borders и device-pixel strokes.
- 4px-oriented scale — default, но не причина искажать Figma values.
- Components используют semantic tokens вместо повторяющихся raw values.

## Cascade

- Предпочитать single-class selectors.
- Compound selector допустим для combo: `.button.is-secondary`.
- State лучше выражать атрибутом: `[aria-expanded="true"]`.
- Не использовать ID для styling и избегать `!important`.
- Tilda collision исправлять scope под уникальным page root.

## Responsive

Default bands при отсутствии иных данных:

```text
mobile portrait     <= 520px
mobile landscape    521–767px
tablet              768–1024px
desktop             >= 1025px
```

CSS пишется mobile-first. Figma pixels являются измерениями для отношений, а не
разрешением заморозить layout. Колонки переводятся в `fr`/проценты, containers —
в `width: 100%` + `max-width`, высота остаётся content-driven.

После изменения breakpoint обязательно проверяются обе соседние ширины на его
границе: `520/521`, `767/768` и `1024/1025px`. Это исключает однопиксельные разрывы
между диапазонами и расхождение CSS с JavaScript `matchMedia`.
