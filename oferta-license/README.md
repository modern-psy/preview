# Публичная оферта на заключение лицензионного договора

Источник: PDF «Оферта лицензионная АСП» от 21 апреля 2026 (7 страниц, страницы 6–7 сканы с подписью и печатью).
Отдельная оферта для доступа к материалам в записи, не путать с офертой образовательных услуг в `../oferta`.

Состав:
- `index.html` — весь текст оферты, договора и Приложения № 1 «Правила общения». Формулировки, нумерация и реквизиты перенесены из PDF без изменений, кроме регистра заголовков (обычный вместо заглавных).
- `style.css` — копия `../oferta/style.css`, здесь не править.
- `page.css` — стили только этой страницы: серые ячейки терминов, серые плашки «Лицензиат не вправе:» и т. п., ширина второй подписи.
- `assets/signature-1.jpg`, `assets/signature-2.jpg` — подписи с печатью, вырезаны со страниц 6 и 7 PDF.

Запуск: preview-сервер из `.claude/launch.json` или `python3 -m http.server 8841 --bind 127.0.0.1` из `apps/preview`,
затем открыть `/oferta-license/`. JavaScript не нужен.

Пакет для Тильды: `python3 apps/preview/oferta-license/build-tilda.py` из корня репозитория. Результат в `tilda/`
(STYLE-01, STYLE-02, 01-BODY, 02-BODY, preview.html) и архив `oferta-license-tilda.zip`. Подписи в пакете берутся с S3
(ссылки в `ASSET_URLS` сборщика), файлы совпадают с `assets/`. Порядок вставки в `tilda/README.md`.

Не решено: адрес страницы на сайте (canonical не стоит). Не закоммичено.
