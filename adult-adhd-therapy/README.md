## Как завести курс в CMS

Курс `adult-adhd-therapy` в CMS уже есть: один поток со статусом «Лист ожидания», без дат и цен, бронь
5 000 ₽. Чтобы блок цены показал «Один вебинар» и «Весь цикл» с выгодой, в этом потоке поменять:

| Поле потока | Значение |
|---|---|
| Название (label) | Цикл вебинаров 31 января |
| Дата старта (startDate) | 31.01.2027 |
| Расписание (schedule) | 31 января, 28 февраля и 28 марта, 15:00–19:00 |
| Дни занятий (lessonDays) | Воскресенье |
| Статус | Идет набор |
| Цена брони (bookingPrice) | очистить: бронь бывает только в листе ожидания |
| Тарифы | включить и завести два тарифа (ниже) |

| Тариф | Цена | Остальные поля |
|---|---|---|
| **Один вебинар** | 7 000 | пусто: без оплаты сразу, без рассрочки, без графика повышений |
| **Весь цикл** | 19 000 | так же |

Названия тарифов важны: блок узнаёт тарифы по словам «Один вебинар» и «Весь цикл» в названии
(«Весь цикл из трёх встреч» тоже подойдёт). Что «Весь цикл» — пакет из трёх вебинаров, в CMS не задаётся:
это записано в `price-sync.mjs` (`kind: 'bundle'`, у вебинара `count: 3`). Выгода на ярлыке считается
от цен CMS: 3 × 7 000 − 19 000 = **«Выгода 2 000 ₽»**. Поменяются цены в CMS — ярлык пересчитается сам.

Как курс должен прийти из Public API после правок — `cms-course.json`. Проверить:
https://modern-psy-asp-prod-8ceb.twc1.net/api/public/course/adult-adhd-therapy

Если повышений цены не будет, график цен оставить пустым. Если будет — блок сам покажет плашку
«С … : N ₽» у каждого тарифа.

## Блок цены

`node adult-adhd-therapy/price-sync.mjs` (из apps/preview) вставляет блок генератора /pricing между метками
`price:start/end` и микроразметку курса между `price-ld:start/end`. Утверждённый сценарий 6 витрины
/pricing-scenarios: «Один вебинар» белой карточкой, «Весь цикл» тёмной с ярлыком «Выгода N ₽».

Пока курс в CMS не заведён, в превью стоит **предпросмотр** по `cms-course.json`
(`price-sync.mjs --draft`): блок не ходит в CMS и помечен `data-price-draft`, `build-tilda.mjs` такой не соберёт.
После правок в CMS запустить `price-sync.mjs` без `--draft`.

Для этой страницы генератор научился двум вещам (07.11.2026, `pricing/src/price-auto.js`):
- `count` у модуля — сколько таких модулей в пакете (выгода «3 × вебинар − цикл»);
- `installment: false` — без строки «или N ₽/мес в рассрочку»: для 7 000 ₽ выходило 292 ₽/мес.

«Гибкие условия оплаты» (рассрочка до 24 месяцев, персональные скидки, вычет) **выключены**: неизвестно,
действуют ли они на вебинары. На живой странице они сейчас видны (стоят в блоке листа ожидания).
Включить — `terms: true` в `price-sync.mjs`.

## Форма

`node adult-adhd-therapy/request-form-sync.mjs` — общий компонент request-form, режим «курс». Заявка уходит
через нативную форму Тильды, которая уже стоит на странице (rec1981798501). У неё имя **course-rl**:
форма скопирована со страницы /course-rl, поэтому заявки с этой страницы приходят с тем же именем формы.
Источник в заявке — «Вебинары «Тонкости работы со взрослыми с СДВГ»» (поле form_source), по нему их можно
отличить. Если форму в Тильде переименуют, поменять `nativeMarker` в скрипте и пересобрать.
