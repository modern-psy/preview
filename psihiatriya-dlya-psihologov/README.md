# Психиатрия для психологов

Лендинг курса повышения квалификации. Превью: https://modern-psy-preview-5a99.twc1.net/psihiatriya-dlya-psihologov/

Собран 15.10.2026 из утверждённого макета (артефакт «Блоки лендинга „Психиатрия для психологов“», версия 11).
Сборки нет: `index.html`, `page.css`, `page.js` правятся напрямую.

## Блоки сверху вниз

1. Первый экран: два облака точек (психология и психиатрия), в пересечении фиолетовые вспышки (canvas в page.js).
2. «Когда привычного понимания запроса уже недостаточно»: тёмная плашка, чипсы запроса, колода из пяти ситуаций.
3. «Не становиться психиатром»: лист «Разбор случая» заполняется при появлении, печать «решение обосновано».
4. «Кому подойдёт программа»: три карточки и фото (Tilda CDN, как на «Терапии травмы»).
5. «Программа курса»: путь сверху вниз, четыре остановки.
6. «Теорию изучаете заранее…»: лекция в записи и встречи по четвергам, рисунки описаний.
7. «Преподаватель курса»: Анжела Баззаева, фото в img/anzhela-bazzaeva.webp (800×800, для Тильды загрузить на S3).
8. Удостоверение о повышении квалификации и сертификат Академии (фото удостоверения на S3).
9. «Стоимость обучения»: «Одна цифра» с составом «Что входит» (галочки собраны с текстов страницы), 30 000 ₽ статично, рассрочка 1 250 ₽/мес по правилу «цена ÷ 24», ниже «Гибкие условия оплаты».
10. Лид-форма.
