Лендинг курса повышения квалификации. Превью: https://modern-psy-preview-5a99.twc1.net/psihiatriya-dlya-psihologov/

Собран 15.10.2026 из утверждённого макета (артефакт «Блоки лендинга „Психиатрия для психологов“», версия 11).
`index.html`, `page.css`, `page.js` правятся напрямую. Блоки T123 для Тильды собирает `build-tilda.mjs`

**С 26.10.2026 стоит на общих стилях лендингов v1** (`apps/preview/academy-base`, на сайте — custom.css Тильды):
- шрифт Wix Madefor из v1, Google Fonts и Wix Madefor Display убраны; на превью подключены `/academy-base/v1.css` и предзагрузка шрифта;
- метка `data-academy="1"` на обёртке `.psy-page`, в пакете Тильды — на обёртке каждого блока;
- H1 — класс `hero_heading` (28 → 48 px), кнопки — `button_component`, остальные тексты берут размеры из переменных
  `--title`, `--sub`, `--body`, `--h3`, `--caption`, `--fine`, значения которых совпадают с ролями v1 (текст 16 на телефоне,
  описание 18, заголовок карточки и вопроса FAQ 22, подпись 15, сноска 14); заголовки секций 500, как в v1;
- в `academy.css` копии ролей текста убраны, их даёт v1. Превью пушить только вместе с папкой `academy-base`.
(из `apps/preview`: `node psihiatriya-dlya-psihologov/build-tilda.mjs`), результат и инструкция в `tilda/`.

## Данные из CMS

С 27.10.2026 дата старта, часы и время практики берутся из CMS (page.js, раздел «Дата старта, часы и время практики из CMS»):
ближайший поток курса psychiatry-for-psy (`/api/public/course/…`: дата, «по вторникам, 17:00–19:00 мск») и часы из каталога
(`/api/public/catalog`). Места на странице помечены `data-cms`: start, hours, schedule-days, schedule-time (первый экран,
факты программы, два ответа FAQ). Ответы FAQ с этими метками скрипт переписывает и в микроразметке FAQPage. Если API
не ответил, остаются тексты страницы. Цены на сайте показывает блок цены из генератора /pricing, он сам ходит в CMS.

3. «Зачем психологу знания психиатрии»: слева зачем (лид и абзац), справа лист «После обучения вы сможете» с пятью умениями. Сделан 26.10.2026 вместо «Не становиться психиатром». С того же дня лист без наклона и заполняется при прокрутке: тёмная плашка целиком стоит на экране под фиксированной шапкой сайта (её высоту скрипт находит сам; на телефоне шапки нет, плашка стоит так, чтобы лист был посередине), пока страницу листают вниз, лист раскрывает умения по одному, после пятого ставит печать «решение обосновано». Запас прокрутки лежит под плашкой, фон не растягивается; высота листа закреплена по самому длинному пояснению. Если лист не помещается в экран (маленький телефон, телефон боком), закрепления нет и видны все пояснения (выбран вариант В из артефакта https://claude.ai/artifact/QPAVJskjtqmhzAy4tGBMX5).
