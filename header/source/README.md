# Шапка modern-psy.ru с поиском · сохранённая версия

Ветка `header-search` в modern-psy/preview. Здесь лежит новая шапка сайта в том виде,
в каком её собрали 24 октября 2026: исходники, готовые блоки для Тильды и пробная страница.
Ветка нужна, чтобы эти наработки не потерялись: в `main` папка `header/source` не попадает,
а Timeweb собирает превью только из `main`, поэтому на сайт превью ничего отсюда не выкладывается.

Пробная страница `header/index.html` в этой ветке та же, что на
https://modern-psy-preview-5a99.twc1.net/header/ (коммит 117fae5).

## Что внутри

| Файл | Что это |
|---|---|
| `tilda/header.html` | первый блок T123: шапка и меню «Все курсы» со снимком курсов из CMS |
| `tilda/header-search.html` | второй блок T123, ставится сразу под первым: поиск по курсам и скрытие шапки при прокрутке |
| `src/nav.json` | ссылки шапки, разделы, кнопки, надписи и быстрые запросы поиска |
| `src/header.css`, `src/header-render.js`, `src/header-client.js` | вид шапки, как рисуются курсы, поведение меню |
| `src/search-core.js` | движок поиска: раскладка, опечатки, поисковые слова, преподаватели, темы |
| `src/header-search.js`, `src/header-search.css` | поиск в шапке: поле в меню телефона, панель на десктопе, результаты |
| `src/header-autohide.js`, `src/header-autohide.css` | шапка прячется при прокрутке вниз и мягко выезжает при прокрутке вверх |
| `build.mjs` | сборка обоих блоков и пробной страницы |
| `preview.html` | пробная страница, как она была собрана |
| `vendor/catalog-data.js` | общий загрузчик каталога (оригинал: `asp-deploy/apps/tilda/catalog-live/src/catalog-data.js`) |

## Что в этой версии

- На телефоне в строке шапки: логотип, поле «Найти курс» и кнопка «Все курсы». «Календарь обучения» первой ссылкой в меню, с 768 px снова в строке.
- Поиск по курсам без своего сервера: понимает сокращения в обеих раскладках, неправильную раскладку, опечатки, окончания, поисковые слова курсов, темы запросов и преподавателей из CMS. На телефоне поле наверху меню, на десктопе панель под шапкой.
- «О нас», «Акции», «Новости» и «Документы» собраны в выпадающий пункт «Академия».
- Шапка липкая на всех экранах. Прячется при прокрутке вниз и мягко выезжает при прокрутке вверх: на телефоне сразу, на десктопе после 80 px вниз и 160 px вверх.
- Ширина как у лендингов: содержимое 1520 px и поля до 80 px.
- Пока меню открыто, чаты и баннер cookie скрыты.

## Как вернуть в работу

1. Скопировать содержимое этой папки, кроме `vendor`, в `asp-deploy/apps/tilda/header`.
2. Проверить, что на месте `asp-deploy/apps/tilda/catalog-live/src/catalog-data.js`; если нет, положить туда `vendor/catalog-data.js`.
3. Из корня asp-deploy собрать: `node apps/tilda/header/build.mjs`. Сборка обновит оба блока, `preview.html` и `apps/preview/header/index.html`.

## Что не сделано перед выкладкой на сайт

- Поисковые слова, темы поиска и преподаватели у курсов лежат в ASP-Prod (коммит 4540606). Пока CMS и API с ними не выкачены, поиск на сайте ищет только по названиям курсов.
- Оба блока ещё не стоят на странице-шапке Тильды (headernew, блок rec4724257201). Ставить только с согласия Дарьи.
- В Метрике нужно завести цели «JavaScript-событие»: site_search, site_search_empty, site_search_click.
- Дальше по плану: полоса курса с разделами страницы, хлебные крошки, тесты «Две двери» и «Подобрать курс».
