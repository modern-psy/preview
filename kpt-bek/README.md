# КПТ: Когнитивно-поведенческая терапия. Модель Бека

Пересборка живой страницы https://modern-psy.ru/kpt (20.10.2026). Заказа на редизайн не было, поэтому
композиция, состав блоков, тексты и картинки (Tilda CDN) взяты со страницы как есть. Из web-academy взяты
шрифт, отступы, адаптив (521 / 768 / 1025 px) и профиль анимаций (150 / 300 / 400 мс).

Превью: https://modern-psy-preview-5a99.twc1.net/kpt-bek/

## Как править

Тексты — в `data/content.json`, стили блоков — в `page.css`, поведение — в `page.js`. Потом из `apps/preview`:

```sh
node kpt-bek/build.mjs
```

Сборка пишет `index.html`, `style.css`, `script.js`. Их руками не править. Сборке нужны папки
`web-academy/shared/academy` (форма, FAQ, диплом) и `pricing/src` (блок цены). Папка `pricing` есть
только локально, в git её нет, поэтому собирать можно только на этом компьютере.

## Блоки сверху вниз

1. Первый экран: светлая карточка, текст слева, фото справа. На телефоне и планшете под текстом
   горизонтальная версия того же фото. Кнопки «Оставить заявку» (к форме) и «Посмотреть программу».
2. «Этот курс подойдёт опытным и начинающим психологам»: пять модулей и сиреневая плашка с фактами.
   «Ближайший старт» берётся из CMS (ближайший поток с открытым набором).
3. «Почему стоит освоить методы КПТ»: тёмная плашка #1d1d33 (цвет живой страницы), фото и четыре карточки.
4. «Чему вы научитесь на курсе»: четыре карточки по два пункта.
5. «Программа обучения»: сиреневая плашка, слева табы пяти модулей, справа описание и темы.
   До 1025 px та же разметка работает аккордеоном.
6. Бесплатные лекции. Кнопка «Получить доступ» открывает нативный поп-ап Тильды `#free-bek`
   (так он называется на живой странице). На превью поп-апа нет, кнопка ничего не делает.
7. Преподаватели: 11 имён вкладками и карточка выбранного.
8. «Почему выбирают нас»: пять карточек.
9. Диплом: общий блок Академии, номер лицензии ведёт в реестр Рособрнадзора.
10. Видеоотзывы: семь карточек лентой, видео Kinescope включается прямо в карточке, без поп-апа.
11. Цена: утверждённый блок цены из CMS (`pricing/src`, курс `kpt`), два потока переключаются сверху.
    «Что входит» собрано из текстов страницы (`pricing.includes` в `content.json`).
12. Форма заявки: лид-форма библиотеки, нативная форма Тильды `kpt-bek`. Заголовок «Занятия начнутся …»
    с датой ближайшего старта из CMS.
13. FAQ: девять вопросов с живой страницы.

## Что изменилось относительно живой страницы

- Поп-апы формы (`#form`, `#form1`) убраны: все кнопки ведут к форме на странице.
- Отдельный блок «Рассрочка от банков / от Академии» убран: условия оплаты теперь внутри блока цены,
  а рассрочку от Академии по правилам блока цены не упоминаем.
- Программа: часы исправлены по-русски (137 академ. часов, 132 академ. часа), у модуля «Практические
  навыки» взяты темы десктопной версии (в мобильной были лишние).
- Мелкие опечатки: «программы..», незакрытая скобка у Сергея Падве, «концептуализация Бека» в FAQ.
