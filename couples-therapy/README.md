## Что берётся из CMS

| Что | Откуда | Где на странице |
|---|---|---|
| Набор или лист ожидания, дата старта | `/api/public/catalog`, карточка `couples-therapy`: `mode`, `startDate` | строка под кнопками первого экрана (`data-cms="start"`), заголовок формы (`data-cms="enrollment-start"`) |
| Часы | каталог: `hours` | первый факт под первым экраном (`data-cms="hours"`) |
| Время занятий | `/api/public/course/couples-therapy`: первое предложение `schedule` продаваемого потока, «раз в неделю» — если в `lessonDays` один день | подзаголовок программы (`data-cms="schedule-sentence"`) |
| Цены, повышения, рассрочка | курс в CMS, блок генератора /pricing | блок цены `#price`, микроразметка Course |
