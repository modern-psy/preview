# Второй уровень РО ДБТ · /rodbt-lvl2

Живая страница: https://modern-psy.ru/rodbt-lvl2 (Тильда, блоки Zero). Курс в CMS — `ro-dbt-2`.

## Задача (17.11.2026)

Перевести страницу на общие стили v1, сохранить тексты и контент, дизайн по возможности повторить, иконки Lucide,
страница цветная. Кнопки — как на /ro-dbt-path. Программа — четыре части по три блока вместо двенадцати блоков подряд.
Блок цены не трогать: он верный и вписан вручную (CMS пока не выкатывается). Форма заявки — общий компонент,
нативная форма Тильды `rodbt-lvl2` (варианты Telegram и Max, от Дарьи 17.11.2026).

Примечание: в задаче было «CSS v2», но файла `academy-base/v2.css` пока нет; страница на v1 (`data-academy="1"`),
как /ro-dbt-path.


### Отличия от старой страницы

- Якорь `programma` стоял перед «Дорожной картой»; теперь это id блока программы, на него ведёт «Смотреть программу».
  У дорожной карты свой якорь `etapy`.
- Подпись «Этап 2 · Практика» и статус «Доступно пять блоков» на старой странице стояли у Модуля 3 (по координатам Zero);
  по смыслу это Модуль 2, перенесены к нему. У Модуля 3 — «Практика» и «Скоро в продаже», как на /ro-dbt-path.
  Слово «Этап N» ушло в номер в кружке (без средней точки).
- Опечатки: самоииследования, сигнализаци, сверконтролирующих, «Ловушка собственной исключительности» без открывающей
  кавычки, «моральными Эмоциями», «Стратегии Повышения», «Анализ принятия решений», «избыточнонесогласный», «объемный»,
  дефис вместо тире («По итогу - сертификат», «Путилова - члены»), «факультативных-поддерживающих».
- Форма: три абзаца слева («Важно: …», «Начните с группы самообучения…», «После оплаты…») заменены одним подзаголовком
  (текст в `sync-blocks.mjs`): «блоки 1–3 сразу» относится к оплате всех четырёх частей (уточнение Дарьи 17.11.2026).
