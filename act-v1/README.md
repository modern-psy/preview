# АСТ: Терапия принятия и ответственности на стилях v1 (/act-v1)

Пересборка https://modern-psy.ru/act (страница Тильды 32459650) на общих стилях v1 (`apps/preview/academy-base`),
11.11.2026, блоки утверждала Дарья по одному. Превью: https://modern-psy-preview-5a99.twc1.net/act-v1/

## Сценарии

Запуск из `apps/preview`:

- `node act-v1/price-sync.mjs` — блок цены и разметка курса из `apps/tilda/pricing-auto/act.html` и `act-ld.html`
  (тот же блок, что rec4766225501 на живой /act);
- `node act-v1/request-form-sync.mjs` — форма заявки (общий компонент, нативная форма `act`, rec1084768151);
- `node act-v1/build-tilda.mjs` — пакет `tilda/` (20 блоков T123) и `tilda/preview.html`.

Копии `academy.css`, `diploma.css`, `request-form.css`, `request-form.js` руками не править.
