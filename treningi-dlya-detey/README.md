# Практика создания и проведения тренингов для детей и подростков — лендинг курса

Адрес превью: https://modern-psy-preview-5a99.twc1.net/treningi-dlya-detey/ . Собран 12.10.2026 по ТЗ (текст в чате, Figma нет).

Задача первой версии — проверить общие блоки Академии (`web-academy/shared/academy`) на новом лендинге:
страница собрана из них, своего кода минимум. Что пришлось доделать поверх общих блоков — в разделе «Что не хватило в общих блоках».

## Как править и собирать

| Что менять | Где |
| --- | --- |
| Тексты, ссылки, картинки | `data/*.json` |
| Тема (`.treningi-dlya-detey-page`) и маленькие проектные дополнения | `page.css` |
| Состав и порядок секций | `build.mjs` |

Из `apps/preview`:

```sh
node treningi-dlya-detey/build.mjs          # data + page.css + shared/academy -> index.html, style.css, script.js
node treningi-dlya-detey/build-tilda.mjs    # index.html -> tilda/*.html (по одной секции на T123), preview.html, manifest.json
```

`index.html`, `style.css`, `script.js` и `tilda/` генерируются, руками их не правят.
Все картинки на S3 (21.10.2026), пакет Тильды собирается без флагов: 19 блоков T123 в порядке `tilda/manifest.json` —
3 блока стилей, 13 секций, 2 блока скриптов и JSON-LD; каждый в отдельный T123 с нулевыми отступами.

## Что не хватило в общих блоках

Найдено при сборке, решено на уровне лендинга точечной заменой разметки в `build.mjs` (если общий блок изменится,
сборка остановится и скажет, где). Кандидаты на общие варианты:

1. **course-audience** — нет плашки под карточками; блок в итоге заменён проектным «Две точки старта».
2. **foundation / CTA** — CTA без кнопки («акцентная плашка») не предусмотрен; блок в итоге заменён проектным «Ваш готовый тренинг».
3. **program** — одна кнопка; в ТЗ две. Блок в итоге заменён табами модулей (см. ниже); «Скачать полную программу» в состоянии превью, пока нет файла.
4. **CTA** — цвет заголовка на тёмном фоне не задан самим блоком: без строки `.cta_copy { color }` в теме текст не виден (на странице CTA больше нет).
5. **teachers** — для двух преподавателей слайдер с табами избыточен; статичной сетки из teacher-card в библиотеке нет, собрана в `page.css`.
6. **«Вопросы на небе»** был только внутри «Клинического психолога». 12.10.2026 вынесен в общие
   (`client-questions-render.mjs`, `.css`, `.js`, `.md`), этот лендинг — второй потребитель. «Клинический» пока на своей копии.
7. **«Гибкие условия оплаты»** живёт только в витрине `/pricing-scenarios`; разметка и стили перенесены в лендинг.
8. **Заголовок academy-showcase** обязательно с акцентной второй строкой; для «Почему выбирают нас» она вырезается.

## Данные из CMS

Курс в CMS — слаг **`child-training-practice`** (21.10.2026; адрес страницы остаётся `treningi-dlya-detey`). Public API
`https://modern-psy-asp-prod-8ceb.twc1.net`, настройки в `data/pricing.json` → `api`, `slug`. Код — `cms.js`: при сборке
он вшивает снимок (`node treningi-dlya-detey/build.mjs --refresh` → `data/api-course.json`), в браузере один раз
спрашивает API и подменяет значения. Пустое поле в CMS или API не ответил — остаётся запасное значение из `data/pricing.json`.

| Что | Атрибут | Где | Поле CMS |
|---|---|---|---|
| Название | `data-cms-title` | первый экран, карточка цены | название курса |
| Старт | `data-cms-start="… {date}"` | плитка первого экрана, цена, заголовок формы, FAQ | дата старта потока |
| Дни занятий | `data-cms-schedule="… {schedule}"` | подзаголовок программы, «Что входит», FAQ | расписание потока, иначе дни занятий |
| Документ | `data-cms-document` | факты под первым экраном, «Что входит» | документы курса (первый) |
| Часы | `data-cms-hours="… {hours}"` | факты под первым экраном, «Что входит», FAQ | часы (только через каталог) |
| Цена | `data-cms-price`, `-benefit`, `-installment`, `-rise` | карточка цены и `offers` в JSON-LD | цена, цена при оплате сразу, рассрочка, ближайшее повышение |

Что сейчас в CMS (21.10.2026): старт 4 марта, 30 000 ₽, рассрочка 1 250 ₽/мес на 24 мес, с 26 ноября 32 000 ₽
(показывается серой плашкой «подорожает на 2 000 ₽»), документ — удостоверение, дни — «Четверг».
Два поля не приходят:
- **время занятий**: в потоке нет строки расписания, только день. Дни из CMS без времени не затирают запасную строку
  «по четвергам с 17:00 до 20:00», если день тот же. Заполнить в CMS «Расписание» (например «По четвергам 17:00–20:00»),
  тогда время тоже пойдёт из CMS;
- **часы**: API отдаёт их только в каталоге, а у курса выключено «Показывать в каталоге». Пока на странице 60 из
  `data/pricing.json`; когда курс появится в каталоге, часы подтянутся сами.
