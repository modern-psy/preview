## Правила для следующих блоков

- Каркас каждой секции: `<section class="… section-spacing_component">` → `padding-global` → `container-xlarge`.
- Боковые поля до 767 px — ровно 16 px, как на /neurodivergence и «Психиатрии» (решение Дарьи 05.11.2026);
  задано один раз токеном `--page-padding` на `.main-wrapper.child-psy-page` в page.css, от 768 px — формула v1.
  В секциях поля отдельно не задавать.
- Размер текста — только классом роли v1. В page.css не задавать `font-size`, `line-height`, `font-weight`
  у текста и поля кнопки; раскладку, ширины, фон и цвет задаёт страница.
- Переломы `@media` только 32.5625rem / 48rem / 64.0625rem.
- Иконки Lucide 20 px, нейтральные.
- Поля карточек 16 px (`--card-padding`), у крупных плашек на компьютере до 24 px. В карточках одной высоты
  заголовок прижат к верху, абзац к низу (просьба Дарьи 05.11.2026), а не всё по центру.
- Кнопка `button_component`: высоту, кегль и поля не трогать; ширину задаёт родитель. В первом экране, тарифах
  и форме кнопка растянута (как `.hero_actions` в web-academy: на ширину колонки, не шире 38.3125rem),
  по ширине текста — только в CTA по адаптиву (`web-academy/shared/academy/button.md`). Правка Дарьи 05.11.2026:
  узкая кнопка по ширине текста в первом экране — «не по дизайн-системе web-academy».
