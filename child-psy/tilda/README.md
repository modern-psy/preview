# Детская психология: блоки T123 для Тильды

Страница: https://modern-psy.ru/child-psy (Тильда, страница `63245651`, папка «Курсы»).
Блоки собирает `build-tilda.mjs` из `index.html`, `page.css`, `page.js`, `academy.css`, `diploma.css` и копий формы заявки.
Файлы `NN-*.html`, `preview.html` и `manifest.json` руками не править: при следующей сборке они перезапишутся.
Правим исходники и пересобираем из `apps/preview`:

```sh
node child-psy/price-sync.mjs
node child-psy/build-tilda.mjs
```

`preview.html` — все блоки в обёртках, как их рисует Тильда, вместе с правилом ссылок из custom.css сайта.
Открывать через локальный сервер (общие стили v1 подключены по относительной ссылке). Все картинки с CDN
(static.tildacdn.com, optim.tildacdn.com и S3 asp-media). Высота страницы в `preview.html` совпадает с превью
лендинга на 375 и 1440 px (проверено 05.11.2026).

## Общие стили v1

Шрифт Wix Madefor, H1, кнопки и роли текста приходят из custom.css сайта (вставка «общие стили лендингов»).
В пакете их нет. Каждый блок обёрнут в `main-wrapper academy-page child-psy-page` с меткой `data-academy="1"`:
без неё блок останется на старой типографике.

## Как стоит на странице (залито через MCP 05.11.2026)

Старые блоки страницы Дарья скрыла в редакторе, видимыми оставлены попап бесплатных лекций и нативная форма.
Пакет залит после них скриптом `node scripts/tilda-mcp.mjs upload apps/preview/child-psy/tilda 63245651 --after=…`
(из корня asp-deploy), проверка — `verify` с теми же путём и номером страницы.

| Блок | Что внутри |
